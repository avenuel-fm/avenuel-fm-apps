## ⚠ 먼저 읽어 주세요: 주소는 TinyURL로 나눠 줍니다 (「현재 파일을 열 수 없습니다」 오류 대책 포함)

- **정한 방법**: 직원에게는 웹앱 주소 대신 **TinyURL 짧은 주소**(예: `tinyurl.com/avenuel-ws`)를 나눠 주고, 홈 화면에 추가하게 합니다.
- **연결 순서**: `TinyURL 짧은 주소` → `바로가기 페이지(껍데기, GitHub Pages)` → `구글 웹앱(/exec)`
- **TinyURL을 웹앱 주소에 바로 연결하면 안 되는 이유**:
  - 휴대폰·PC 브라우저에 **구글 계정이 2개 이상 로그인**되어 있으면, 구글이 웹앱 주소를 계정 번호가 붙은 주소(`…/macros/u/1/s/…`)로 바꿉니다. 그러면 「Drive · 현재 파일을 열 수 없습니다」가 납니다.
  - TinyURL은 주소를 그대로 넘겨주기만 하므로, 웹앱에 바로 연결하면 이 오류가 그대로 납니다. 앱 코드 문제가 아니라 구글 웹앱 전체의 현상이라 도면협의 등 다른 앱도 같습니다.
  - 그래서 TinyURL과 웹앱 사이에 **바로가기 페이지(껍데기)**를 하나 둡니다. 껍데기가 웹앱을 자기 화면 안에 띄우므로 주소가 바뀌지 않습니다. 웹앱 쪽은 다른 페이지 안에서 열릴 수 있게 허용해 두었습니다(`ALLOWALL`).
- **덤**: 무료 TinyURL은 만든 뒤 연결 주소를 바꿀 수 없습니다. 껍데기를 거치면 웹앱 주소가 바뀌어도 `apps.js` 한 줄만 고치면 되고, TinyURL과 이미 붙인 QR은 그대로 씁니다.
- **QR 라벨은 TinyURL이 아니라 껍데기 주소를 씁니다.** QR에는 소화기마다 고유번호(`?fe=…`)가 붙는데, TinyURL을 거치면 이 값이 빠질 수 있어서입니다. 설정의 `바로가기주소`를 넣으면 자동으로 이렇게 만들어집니다.
- **설치 전 바로 시험하는 방법**: 크롬 **시크릿 탭**에서 웹앱 주소를 열거나, 브라우저에서 구글 계정을 하나만 남기고 로그아웃합니다.

## 1. 설치 (약 10분)

> 앞으로 정식판을 쓸 **시설팀 공용 구글 계정**으로 하는 것을 권장합니다.

1. **구글 시트 새로 만들기**
   - 이름 예: `20_업무지원_DB (테스트)`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. **파일 넣기**
   - 처음 있는 `Code.gs` 내용을 모두 지우고, 받은 `Code.gs` 내용을 붙여 넣습니다.
   - 왼쪽 **＋ → HTML**로 파일 3개를 만들고, 이름을 정확히 `Index`, `Check`, `Styles`로 합니다(`.html`은 자동으로 붙습니다). 각 파일에 받은 내용을 붙여 넣습니다.
   - 왼쪽 **⚙ 프로젝트 설정 → 「appsscript.json 매니페스트 파일 표시」**를 켭니다. 편집기에 나타난 `appsscript.json` 내용을 받은 파일로 바꿉니다.
   - **저장**(디스크 아이콘)을 누릅니다.
4. **초기 설정**
   - 시트 탭으로 돌아와 **새로고침**합니다.
   - 위 메뉴에 **업무지원**이 생기면 **① 초기 설정**을 누릅니다.
   - 처음에는 권한 승인 창이 뜹니다. 계정을 고르고 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 직접 만든 스크립트라서 나오는 안내입니다.
   - 탭 5개(설정, 직원, 소화기, 소화기점검, 변경기록)가 생기고, 드라이브에 `시설팀 통합업무 › 20_업무지원 › 소화기점검 › 2026-11` 폴더가 만들어집니다.
5. **직원 등록**
   - 메뉴 **업무지원 › ② 직원 등록**에서 이름, PIN, 파트, 역할을 넣습니다.
   - PIN은 휴대폰 뒷 4자리입니다. 같은 PIN은 등록되지 않습니다.
   - 여기 넣는 직원은 실제 직원으로 계속 씁니다. 그만둔 직원은 **⑦ 직원 삭제**로 지웁니다.
6. **웹앱 배포**
   - Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 ⚙에서 **웹 앱**을 고르고 아래처럼 정한 뒤 **배포**를 누릅니다.
     - 실행: **나**
     - 액세스 권한: **모든 사용자**
   - 나온 **웹 앱 URL**(`…/exec`)이 앱 주소입니다. 시트 메뉴 **③ 웹앱 주소 보기**에서도 볼 수 있습니다.
   - 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**로 올립니다. "새 배포"를 다시 하면 주소가 바뀌어서, 이미 붙인 QR이 모두 쓸모없어집니다.

7. **짧은 주소 만들기 (TinyURL + 바로가기 페이지)** (약 15분, 처음 한 번)
   - **가. 바로가기 페이지(껍데기) 올리기** — GitHub Pages, 무료
     1. github.com에 가입합니다. 팀 공용 계정 이메일을 권장합니다.
     2. 오른쪽 위 **＋ → New repository**를 누릅니다. 이름은 `fm`, 공개 범위는 **Public**으로 정하고 **Create repository**를 누릅니다. GitHub Pages 무료는 공개 저장소만 됩니다. 공개돼도 앱 주소만 보이고, 앱 안의 자료는 PIN과 QR 고유번호로 보호됩니다.
     3. **uploading an existing file**을 누르고, `fm` 폴더 **안의** 파일과 폴더를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
     4. **Settings → Pages**에서 Branch를 `main` / `(root)`로 정하고 **Save**를 누릅니다. 1~2분 뒤 `https://계정이름.github.io/fm/`이 열립니다.
     5. 저장소에서 `apps.js`를 열고 연필(✏)을 누릅니다. `ws`의 `exec: ''` 따옴표 안에 6단계의 웹앱 `/exec` 주소를 넣고 **Commit changes**를 누릅니다.
     6. 휴대폰에서 `https://계정이름.github.io/fm/ws/`를 열어 로그인 화면이 나오는지 확인합니다.
   - **나. 앱에 껍데기 주소 알려 주기 (QR용)**
     1. 업무지원 시트 메뉴 **① 초기 설정**을 한 번 더 누릅니다. `설정` 탭에 `바로가기주소` 줄이 생깁니다.
     2. 그 칸에 `https://계정이름.github.io/fm/ws/`를 넣습니다. TinyURL 주소는 넣지 않습니다.
     3. 이제 QR이 껍데기 주소로 만들어집니다. **v0.1 때 인쇄한 QR은 다시 인쇄**해 주세요.
   - **다. TinyURL 만들기 (직원에게 나눠 줄 주소)**
     1. tinyurl.com에 들어가 팀 공용 계정으로 가입·로그인합니다. 만든 주소를 나중에 찾아보기 쉽습니다.
     2. **Long URL** 칸에 `https://계정이름.github.io/fm/ws/`를 넣습니다. **웹앱 `/exec` 주소를 넣지 않습니다.**
     3. **Alias** 칸에 원하는 이름(예: `avenuel-ws`)을 넣고 **Shorten URL**을 누릅니다. 이미 쓰는 이름이면 다른 이름을 넣습니다.
     4. 나온 `https://tinyurl.com/avenuel-ws`를 휴대폰에서 열어 로그인 화면이 나오는지 확인합니다.
     5. 이 주소를 직원에게 알려 주고 **홈 화면에 추가**하게 합니다.
     - 통합 대시보드·도면협의도 같은 방법입니다. `apps.js`의 `hub`·`dw` 칸에 각 웹앱 주소를 넣고, `…github.io/fm/hub/`·`…/fm/dw/`로 TinyURL을 하나씩 만듭니다(예: `avenuel-hub`, `avenuel-dw`). 껍데기 안에서 열리려면 그 앱들에도 이번 `ALLOWALL` 한 줄이 들어가야 합니다(수정 요청 목록 WS-15).
   - **v0.1·v0.2에서 올리는 경우**: `Code.gs`·`Index.html`을 새 내용으로 바꾸고, 시트를 새로고침해 메뉴 ④가 생겼는지 보고, 배포 관리 → ✏ → 새 버전으로 올린 뒤 위 7단계를 합니다.

## 2. 테스트 순서

### PC
1. 웹앱 주소를 열고 PIN으로 로그인 → **점검 → 소화기 점검 → ① 소화기 QR 관리**
2. **＋ 등록**: 층(B1~6F), 매장명, 대수를 넣습니다. "매장명-소화기1, 2…"가 자동으로 붙습니다.
3. 소화기를 고르고 **출력**
   - 먼저 **라벨 미리보기**가 실제 크기로 뜹니다. 기본은 **50×50mm(지금 라벨)**이고, 크기 버튼(50×50 · 40×40 · 30×34 · 50×30)이나 직접 입력으로 바꿀 수 있습니다.
   - **1장 시험 인쇄**로 한 장만 먼저 찍어 위치·크기를 확인한 뒤 **인쇄**를 누르세요.
   - **인쇄**를 누르면 브라우저 인쇄 창이 열립니다. 라벨 프린터를 고르고, 용지를 같은 크기로, 여백 없음, 배율 100%로 맞춰 인쇄합니다.
   - 바꾼 크기는 인쇄할 때 시트 `설정`에 저장되어 다음부터 그 크기로 뜹니다.
   - 라벨 모양: 위에 소화기 이름(예: `샤넬 소화기1`) 한 줄을 작게, 아래에 QR을 크게 넣은 거의 정사각형입니다. 이름이 길면 글자가 저절로 작아집니다(7pt → 최소 4.5pt). 층·안내 문구는 넣지 않습니다.
   - 라벨 크기는 시트 `설정` 탭의 `라벨가로mm`·`라벨세로mm`에서 바꿉니다(기본 50×50mm). **예전 판에서 올린 시트는 30×34 등 예전 값이 남아 있으니 미리보기에서 「50×50 (지금 라벨)」을 누르고 인쇄하면 바뀝니다.**
   - QR은 프린터 해상도(`설정`의 `프린터dpi`, 기본 203)에 맞춰 QR 한 칸이 프린터 점 9개(약 1.1mm)로 딱 떨어지게 그립니다. 그래서 감열·열전사 라벨에서도 칸 경계가 흐리지 않습니다.

#### BIXOLON SLP-TX400 · 50×50 라벨 설정 (PC에서 처음 한 번)
1. **드라이버 설치**: BIXOLON 홈페이지(bixolon.com) 다운로드 → SLP-TX400 **Windows Driver**를 설치하고 USB로 연결합니다.
2. **용지 만들기**: Windows **설정 → 블루투스 및 장치 → 프린터 및 스캐너 → BIXOLON SLP-TX400 → 인쇄 기본 설정**을 엽니다.
   - 용지(Paper) 항목에서 **새로 만들기(New)** → 이름 `라벨 50x50`, **가로 50mm · 세로 50mm**, 여백 0 → 확인
   - 용지 종류(Media Type)는 **갭(Gap · 라벨 사이 틈)**, 방향은 **세로**로 둡니다.
   - 농도(Darkness)는 처음엔 기본값으로 두고, 시험 인쇄가 흐리면 1~2단계 올립니다.
   - 버튼·항목 이름은 드라이버 판에 따라 조금 다를 수 있습니다.
3. **라벨 위치 맞추기**: 라벨지를 넣은 뒤(또는 바꾼 뒤) 프린터 **FEED** 버튼을 눌러 라벨 한두 장이 나오며 틈 위치를 잡게 합니다.
4. **크롬 인쇄 창** (앱에서 [인쇄]를 누르면 뜸)
   - 대상: **BIXOLON SLP-TX400**
   - **설정 더보기** → 용지 크기: **라벨 50x50**(2번에서 만든 것) · 여백: **없음** · 배율: **기본값** · 머리글/바닥글: **끔** · 배경 그래픽: **켬**
   - 크롬은 프린터별로 마지막 설정을 기억하므로 다음부터는 바로 인쇄하면 됩니다.
5. **확인**: 「1장 시험 인쇄」로 찍은 라벨을 휴대폰으로 찍어 점검 입력 화면이 열리면 끝입니다. 위·아래로 밀리면 3번(FEED)을 다시 하고, 좌우로 밀리면 2번 용지 크기를 다시 확인합니다.
4. **삭제**: 고른 소화기를 지웁니다. 지운 QR을 찍으면 "삭제된 QR"로 나옵니다.

### 휴대폰 (직원 화면)
- 같은 주소로 로그인합니다. QR 관리에 **출력 버튼이 없고** 등록·삭제만 되는지 봅니다.

### 휴대폰 (매장 직원 · QR 입력)
1. 라벨을 인쇄하지 않았다면, PC의 QR 관리에서 작은 QR을 눌러 크게 띄운 뒤 휴대폰 카메라로 찍습니다.
2. 열린 페이지에서 확인할 것
   - 로그인 없이 열린다
   - 처음에는 **전송하기**가 회색이고, 버튼 위에 빈 칸이 **빨간 글자**로 나온다
   - **사진 찍기**를 누르면 압력계 모양 흰 원과 "동그라미에 압력계를 맞춰 주세요"가 나온다
   - 손글씨 두 칸(위: 외관·압력 이상무, 아래: 이름)을 다 쓰면 전송하기가 켜진다
   - "이상 있음"을 고르면 위 칸 글자가 "이상 내용"으로 바뀐다
3. **전송하기** → "보냈습니다" 화면
4. 같은 QR을 다시 찍어 보내면 "이번 달 입력이 이미 있습니다 · 바꿀까요?"를 묻습니다.

### 현황 (PC 또는 휴대폰)
1. **② 매장별 소화기 점검 현황**: 월 이동(‹ ›), B1~6F 층 목록, 색 표시
   - 점검완료: 녹색 · 이상 있음: 주황 · 점검 전: 회색 · 미입력: 빨강
2. 층을 누르면 "매장-소화기1, 2…" 목록이 나옵니다. 점검완료나 이상 있음을 누르면 입력한 **사진과 손글씨 두 칸**이 보입니다.
3. **기한 시험**
   - 시트 `설정` 탭의 `점검마감일`을 오늘보다 앞선 날(예: 오늘이 3일이면 `2`)로 바꾸고 1분 뒤 현황을 새로고침합니다.
   - 입력 안 한 소화기가 **미입력(빨강)**으로 바뀌는지 봅니다.
   - 그 상태에서 QR로 입력하면 받아지고 **기한 후**로 표시되는지 봅니다.
   - 시험이 끝나면 `5`로 되돌립니다.

## 5. 데이터가 쌓이는 곳
- **시트 `서명`**: 직원마다 근무일에 한 줄 (ID `WS-SG-근무일-번호`, 근무일, 이름, 파트, 서명 파일 ID, 서명시각(초까지), TBM사용, 삭제여부). 근무일은 오전 6시 시작이라 새벽 5시 59분까지는 전날입니다.
- **시트 `소화기`**: 소화기마다 한 줄 (ID `WS-FE-날짜-번호`, 층, 매장명, 이름, QR 고유번호)
  - 삭제하면 `사용여부=N`으로만 바뀌고 줄은 남습니다.
- **시트 `소화기점검`**: 소화기마다 한 달에 한 줄 (ID `WS-FC-날짜-번호`, 연월, 상태, 사진·손글씨 파일 ID, 입력일시, 기한후입력)
- **드라이브** `시설팀 통합업무/20_업무지원/소화기점검/YYYY-MM/`에 한 번 입력할 때마다 파일 3개가 저장됩니다.
  - `2026-11-03_소화기점검-샤넬-뷰티-소화기1_001.jpg` (압력계)
  - `…_002.png` (외관·압력 이상무 손글씨)
  - `…_003.png` (이름 손글씨)
  - 다시 보내면 예전 파일은 휴지통으로 가고 같은 번호로 새로 저장합니다.
- **보안**
  - QR마다 추측할 수 없는 12자리 고유번호가 들어 있습니다(약 1경 가지 이상, 헷갈리는 l·o·0·1 제외). v0.2까지의 32자리보다 짧아 작은 라벨에서도 QR 칸이 커져 잘 찍힙니다.
  - v0.2 이전에 등록한 소화기(32자리)도 그대로 열립니다. 짧게 바꾸려면 시트 메뉴 **업무지원 › ④ QR 고유번호 짧게 바꾸기**를 누르고, 끝나면 QR을 다시 인쇄합니다(예전 QR은 안 열림).
  - 한 소화기는 한 달에 한 번만 받고, 다시 보내면 바꿀지 묻습니다(결정 1-가).
  - 모든 입력은 `변경기록` 탭에 남습니다.

## 6. 문제가 생기면
| 증상 | 해결 |
|---|---|
| "초기 설정을 먼저 해 주세요" | 시트 메뉴 업무지원 › ① 초기 설정 |
| 웹앱 주소를 열면 구글 로그인이 나옴 | 배포의 액세스 권한이 "모든 사용자"인지 확인 |
| 「Drive · 현재 파일을 열 수 없습니다」 | 구글 계정이 여러 개 로그인된 브라우저에서 웹앱 주소를 바로 연 경우입니다. TinyURL 주소로 여세요. TinyURL로 열었는데도 나오면 TinyURL이 `/exec`에 연결된 것이니 껍데기 주소(`…github.io/fm/ws/`)로 다시 만드세요 |
| QR을 찍으면 다른 주소가 열림 | "새 배포"를 다시 해서 주소가 바뀐 경우입니다. 배포 관리에서 처음 배포를 수정해 쓰거나, QR을 다시 인쇄합니다 |
| QR 그림이 안 나옴 | QR 그림은 인터넷의 QR 도구(cdnjs)로 그립니다. 회사망에서 막혀 있지 않은지 확인해 주세요 |
| 설정 탭 값을 바꿨는데 그대로 | 1분 동안 기억해 두므로 1분 뒤 다시 보세요 |
