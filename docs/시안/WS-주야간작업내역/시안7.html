주간 작업 사진을 「작업 전 · 작업 후」 짝으로 + 식당가 「매장 추가」 칸 (시안 7)

주간작업: 사진을 작업 전 N · 작업 후 N 짝으로 나란히 두고, 짝과 짝 사이에 남색 구분선. 마지막 짝 다음 칸에 점선 「사진 칸 추가」 → 누르면 짝(작업 전·후 2칸)이 하나 늘어남. 처음 2짝, 최대 4짝(지금 서버가 작업 전·후 각 4장까지 받음 — 서버는 안 고침).
휴대폰: 한 줄에 한 짝(전 | 후 2열), 아래에 「사진 칸 추가」. PC: 한 줄에 두 짝(가운데 세로 구분선), 줄이 차면 다음 줄 왼쪽.
식당가 점검: 아래 긴 「＋ 매장 추가」 줄을 없애고 마지막 매장 아래 왼쪽 점선 칸으로(방염집기와 같은 모양).
참고 엑셀 내보내기 칸은 지금처럼 작업 전·후 각 2장까지(3·4짝은 PDF·인쇄에만).
