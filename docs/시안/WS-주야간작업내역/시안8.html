「야간 식당가 점검」을 세 번째 탭으로 (시안 8)

탭: 주간작업 · 야간작업 · 야간 식당가 점검. 야간작업 탭에서는 식당가 점검 칸이 빠집니다.
식당가 점검 탭: 매장명 입력 칸 · 「매장 1」 머리 · 매장 빼기 · ＋매장 추가를 없애고, 사진 칸 묶음 하나만 둡니다. 사진 칸 이름은 「가스누설경보기 · 주방전경」 대신 사진 1, 사진 2 …. 처음 2칸, 「사진 칸 추가」로 30칸까지.
[파일]을 누르면 사진을 여러 장 한꺼번에 고를 수 있고, 누른 칸부터 빈 칸에 차례로 들어갑니다 (칸이 모자라면 30칸까지 저절로 늘어남). [카메라]는 지금처럼 한 장씩.
일자 · 기타사항을 적고 저장 → 아래 목록(월 → 주 → 일)에서 다시 열어 고침. 인쇄 A4 / PDF 보기는 사진만 모아 쪽을 만듭니다.
참고 기록을 따로 두려면 Supabase(자료 창고)에 새 표를 하나 만들어야 합니다 (SQL 한 번 실행). 이미 야간작업에 넣어 둔 식당가 사진은 그 야간작업 인쇄에 그대로 남습니다.
