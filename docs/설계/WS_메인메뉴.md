# WS 메인 메뉴 켜기·끄기 v0.2

> 상태: **11-19 배포** (업무지원 v0.17.0 배포 버전 54 → v0.18.1 꺼진 칸 모양 배포 버전 56). 결정 **148**. 사용자 11-19 시안 보고 「소장 포함, 진행시켜」.
> 시안: `docs/시안/WS-메인메뉴켜기끄기/` (시안1~3, 다시 찍기: `apps/ws`에서 `node ../../docs/시안/WS-메인메뉴켜기끄기/make_mock.js`)

## 1. 요청 (사용자 11-19)
- 「메인 메뉴에 있는 지도 버튼을 관리자와 옵저버 제외하고 직원들에게는 작동되지 않도록 임시 비활성화」
- 「환경설정 메뉴에 메인 메뉴 중 선택한 항목 활성/비활성 선택할 수 있는 기능」
- 지도 막기는 따로 코드로 하지 않고 이 설정에서 지도를 「꺼짐」으로 둠.

## 2. 화면
- **환경설정**(소장만) › 「TBM 위험성 목록」 아래 **메인 메뉴** 칸: 서류작업 · 점검 · 시방서 검색 · 지도마다 「켜짐 / 꺼짐」. 누르면 바로 저장. 「작업중」 칸 2개는 기능이 없어 뺌.
- **메인**: 꺼진 칸은 직원에게 「작업중 · 준비 중」 칸으로 보이고 눌리지 않음 (사용자 11-19, v0.18.1). 「작업중」 칸도 눌리지 않음.
- **꺼진 칸도 여는 사람: 소장·관리자·옵저버** (사용자 「소장 포함」). 이 사람들 메인에는 평소 칸 그대로 (따로 표시 없음).
- 바뀐 설정은 직원이 다음에 메인을 열 때(앱을 열거나 새로 불러올 때) 반영.

## 3. 저장
- Supabase: `settings` 표 key **`메인메뉴끄기`** = 꺼진 칸 이름을 쉼표로 (`docs`, `inspect`, `spec`, `map`), 빈 값 = 모두 켜짐. 알림 표시 시간과 같은 표.
- 구글 판(Apps Script): 「설정」 시트 같은 키. `Code.gs` `menuOff_`·`adminSetMenu`, `bootstrap`이 `menuOff`를 같이 줌.
- 함수 (`supabase/15_menu.sql`): `ws_menu(표)` 꺼진 칸 목록, `ws_admin_set_menu(표, 칸들)` 소장만 저장(모르는 이름 버림, 기록 남김), `ws_menu_guard(역할, 칸)` 서버 막기.
- 앱이 열릴 때 `ws-api.js`가 `ws_bootstrap`과 `ws_menu`를 같이 부름 (15번 SQL을 아직 안 돌렸으면 모두 켜짐으로).

## 4. 서버에서도 막기
- **지도**(`13_map.sql` `ws_map_load`)와 **시방서 검색**(`14_spec.sql` `ws_spec_boot`)은 꺼져 있으면 직원에게 서버가 자료를 주지 않음 → 주소를 직접 쳐도 못 엶.
- 서류작업·점검은 함수가 많아 **화면에서만** 막음 (칸을 눌러도 안 열림).
- 외부용 시방서 검색 페이지(`spec.html`, 로그인 없음)는 이 설정과 상관없음.

## 5. 올리는 순서
1. Supabase SQL Editor: `15_menu.sql` Run → `13_map.sql` · `14_spec.sql` 다시 Run (15번이 먼저 — 13·14가 15번 함수를 부름)
2. 바로가기 저장소: `fm/ws/app.html` · `fm/ws/ws-api.js` (+ `spec.html`)
3. clasp: `Code.gs` · `Index.html`
