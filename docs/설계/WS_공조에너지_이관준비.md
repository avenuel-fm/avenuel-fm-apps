## 3. 옮겨 올 기능 (온습도 앱 6개 탭)
1. **입력(온습도)**: 층(6F→1F→B1F)·구역(1·2·3, B1F는 1구역만) 고르고 실내 온·습도(필수), 실외(선택) → **불쾌지수** DI = 0.81T + 0.01H(0.99T−14.3) + 46.3, 쾌적 <74 · 주의 <78 · 불쾌 ≥78, 권고 문구. 실외 날씨는 Open-Meteo(10분 기억).
2. **그래프**: 최근 5일 온도·습도 (Chart.js 4.4.1).
3. **공조기 가동시간**: 38대, 시작·종료(오전/오후·시·분, 10분 단위), **미가동 = 0시간**, 빈 칸 = 통계 제외. 기본 시각: 시작 10:00, 종료 월~목 19:20·금~일 20:20, **6층 매일 21:50**, **B3층 08:30~18:40**. 폰은 한 페이지 = 한 층, PC는 층(행) × 구역(열) 표가 1920×950 한 화면.
4. **에어커튼 가동시간**: 36대, 9묶음(지하1층 24게이트 2, 1층 1게이트 OUT 7·IN 5, 2게이트 OUT 3·IN 3, 6게이트 OUT 3·IN 3, 후방 피난도어 8, 4층 브릿지 1, 6층 브릿지 1). 기본 종료 20:00, 금토일 19:30.
5. **리포트**: 온습도/공조기/에어커튼. 요약(오늘 미입력 대수·오늘 합계·1대 1일 평균·기간 합계), 오늘 뺀 최근 3일 전일 대비(길면 빨강▲, 짧으면 파랑▼), 추이 그래프(세로축 500시간, 월별 자동), 일일 기록, CSV·인쇄.
6. **설정**: 시트 동기화, 백업/복원, 전체 기간 불러오기.

세부 규칙은 `mall-climate-pwa/config.json`(장비·묶음·기본 시각·판정 기준)과 `CLAUDE.md` 「핵심 규칙」에 있음.

## 4. 옮겨 올 자료 (구글 시트 3장)
| 시트 | 칸 | 한 줄의 뜻 |
|---|---|---|
| `기록` | id, 매장ID, 측정시각, 층, 구역, 실내온도, 실내습도, 불쾌지수, 실외온도, 실외습도, ts | 온습도 측정 1번 |
| `공조기` | id(`날짜|번호`), 매장ID, 날짜, 번호, 가동시작, 가동종료, 가동시간(시간), 급기온도, 배기온도, 수정시각, startMin, endMin, 미가동, 구분 | 공조기 1대의 하루 |
| `에어커튼` | 위와 같음, 번호 = `묶음키-번호` (예 `1G1OUT-3`) | 에어커튼 1대의 하루 |

- **기록은 영구 보관**(몇 년치 통계가 목표). 지우는 기능 넣지 말 것.
- 같은 날짜·번호는 `수정시각`이 최신인 쪽이 이김 (합칠 때도 이 규칙).
- 에어커튼 묶음키(`B1G24`, `1G1OUT`, `1G1IN`, `1G2OUT`, `1G2IN`, `1G6OUT`, `1G6IN`, `1REAR`, `4BR`, `6BR`)는 기존 기록과 이어지므로 **바꾸지 말 것**.
- 화면에서 뺀 공조기 3·37·38번의 옛 기록도 시트에 남아 있음 → 같이 옮기되 통계에서만 뺌.
- 아직 시트에 안 올라간 기록이 기기(폰)에만 있을 수 있음 → 이관 전에 각 기기에서 동기화.

## 6. 합친 뒤 모습 (제안 — 확정 아님)
- 업무지원 메뉴에 새 기능 **「공조 에너지」**(이름 미정): 온습도 입력 · 공조기 가동 · 에어커튼 가동 · 리포트.
- Supabase 새 표 (번호는 이어서 `18_climate.sql` 등):
  - `climate_record` — 온습도 측정 (`기록` 시트)
  - `equip_usage` — 하루 한 장비 한 줄 (kind = 공조기/에어커튼, log_date, unit, start_min, end_min, off, updated_at, editor). 기본키 (kind, log_date, unit)
  - `curtain_unit` — 에어커튼 36대 목록 (묶음키·번호·이름·기본 종료)
  - `ahu_unit` 에 칸 추가 (5장)
  - 화면은 지금처럼 **DB 함수로만** 읽고 씀 (`ws_*` 함수, RLS).
- 종합업무일지는 `?api=logac`(구글 통로) 대신 `equip_usage` 를 바로 합산 → 일지 열기가 빨라짐.
- 자료 옮기기: 시트 3장 → Supabase 한 번에 넣는 SQL/스크립트 (`09_migrate.sql` 처럼), 옮긴 뒤 건수·합계 대조.
- 함께 쓰는 기간: 옛 앱 주소를 바로 닫지 않고, 새 기능이 자리 잡을 때까지 옛 앱은 **읽기 전용 안내**로 둠(제안).
