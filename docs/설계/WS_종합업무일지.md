**2. 계산 규칙 (앱이 함)**
1. **전년 같은 날** = 작성일의 연도만 1 뺀 날짜 (2026-11-13 → 2025-11-13). **2월 29일 → 전년 2월 28일.**
2. 전년 값 찾기: **새 일지 시트 → 없으면 과거자료 시트**. 둘 다 없으면 빈칸(증감·증감율도 빈칸).
3. **월누계** = 그달 1일 ~ 그날 합. **년누계** = 1월 1일 ~ 그날 합. 전년 누계도 같은 방식(전년 1일 ~ 전년 같은 날). 빈 날은 0으로 셈.
4. **증감** = 올해 − 전년 (모든 칸 같은 방향, 엑셀 6번 바로잡음). **증감율** = 증감 ÷ 전년, 소수 첫째 자리 %. 전년이 0·빈칸이면 「—」.
5. **실온수 사용량** = 급탕 − 환탕 (자동, 엑셀 5번 바로잡음).
6. **영업시간 월누계** = 그달 영업시간 합. **월영업일수** = 엑셀처럼 그날 날짜의 일(13일 → 13). *(엑셀 그대로 둠 — 쉬는 날을 빼야 하면 나중에 바꿈)*
7. 계산 값은 시트에 저장하지 않음 (입력 값만 저장, 화면·출력 때 계산). 옛 날짜를 고쳐도 뒤 날짜 누계가 저절로 맞음.

**5. 금일작업 · 자주 쓰는 문구 · 야간 그림 (5단계)**
- **TBM 가져오기**: 그 근무일 TBM 작업 표(`TBM` 탭 `작업표`)의 줄에서 **작업위치 + 작업내용만** 가져옴. 위험요인·재해형태·위험성·안전보건 개선조치는 넣지 않음. 부서 **전방파트 → 전기방재, 기건파트 → 기계건축**. 가져온 뒤 고칠 수 있음. [TBM에서 다시 가져오기]는 덮어쓰기 전에 물어봄.
- **자주 쓰는 문구**: 부서별 문구 칩을 누르면 그 부서 줄 끝에 한 줄 들어감. 시트 탭 `일지문구`(부서 · 문구 · 순서 · 사용여부)에서 소장이 더하고 고침(코드 수정 없음, 위험성목록과 같은 방식).
  - 첫 목록 (11월 엑셀에서 거의 매일 쓴 줄): 전기방재 — 공사장 안전 점검 · 전층 EPS실 순찰 및 점검 · 직무고시 · 전층 알람밸브실 점검 / 기계건축 — 공사장 안전 점검 · 미세먼지 측정 · 일일계량기 검침
- 줄 수: 엑셀은 전기방재 10줄 · 기계건축 15줄 칸. 11월 최대는 10줄 · 11줄. 부서마다 15줄까지.
- **야간 일일 작업 현황**: 그림(사진·캡처) 1장 올리기 → 칸 크기에 맞춰 **자르지 않고 줄여 가운데**(남는 곳 흰색). 2400px·85%로 줄여 드라이브 `…/종합업무일지/{YYYY}/{YYYY-MM}/{YYYY-MM-DD}_야간작업_001.jpg`, 바꾸면 예전 그림 휴지통.

**6. 네이버 날씨 (6단계)**
- 매일 **오후 1시** 예약 작업이 네이버 날씨(잠실동)에서 그때 값을 읽어 그날 줄에 저장: 날씨 · 오늘 최저 · 오늘 최고 · 풍속(오후 1시 값을 「최고풍속」 칸에) · 미세먼지 값·등급.
- 오후 1시 전에 일지를 열면 빈칸(「오후 1시에 자동으로 들어갑니다」). 직접 쓴 값이 있으면 덮어쓰지 않음.
- **주의**: 네이버는 공개 날씨 API가 없어 **검색 화면 글을 읽는 방식**. 네이버가 화면을 바꾸거나 구글 서버 접근을 막으면 끊길 수 있음 → 실패하면 빈칸으로 두고 화면에 「자동 불러오기 실패, 직접 입력」 표시. 6단계 처음에 실제로 읽히는지 먼저 시험.
- 전년 날씨는 과거자료(엑셀 값). **엑셀에 풍속 칸이 없어 전년 풍속은 빈칸.**

**8-1. 만든 것 (3단계, 업무지원 v0.9.11)**
- 서류작업 메뉴 4번째 「종합업무일지」. **화면 가로 1024px 미만이면 「PC에서 열어 주세요」**. 1680px보다 좁은 PC는 종이를 줄여(zoom) 한 화면 폭에.
- 종이 틀 1587×1120px 하나를 화면·인쇄·PDF가 같이 씀. 인쇄 = `@page 364mm 257mm` + 0.867배, PDF = html2pdf `jsPDF mm [364, 257]`.
- 입력하는 동안 막대·누계·증감율이 바로 바뀜 (누계 = 서버 누계 − 저장된 오늘 값 + 화면의 오늘 값).
- 시트는 처음 `logGet` 때 `logBook_`이 만듦 (`SpreadsheetApp.create` → `일지` 탭 → 드라이브 폴더로 옮김 → 설정 탭에 번호). 표 도우미는 `withBook_`로 그 시트를 잠깐 씀.
- 저장 겹침: `수정시각`이 ver. PDF도 ver가 다르면 만들지 않음.
- 야간 그림 칸은 빈 칸(5단계), 날씨 칸은 직접 입력(6단계), 전년 값은 과거자료가 들어오면 보임(4단계).

**8-3. 만든 것 (5단계, 업무지원 v0.9.12)**
- **TBM 가져오기**: `logTbm_(day)` = 그 근무일 `TBM` 작업표, TBM을 아직 저장 안 했으면 `명일작업`(TBM 화면과 같은 규칙). 「작업위치 작업내용」 한 줄, 부서 없는 줄은 뺌, 부서마다 15줄까지. 그날 일지 줄이 없으면(새 시트·과거자료 둘 다) 화면이 **열 때 채워 둠(저장 전)**. [TBM에서 가져오기 (n줄)]은 쓴 내용이 있으면 물어본 뒤 바꿈.
- **자주 쓰는 문구**: 탭 `일지문구`(부서 · 문구 · 순서 · 사용여부) — `logGet` 때 없으면 만들고 5장 첫 목록 7개 넣음. 사용여부 N·모르는 부서는 뺌. 문구 버튼(종이 위, 인쇄 안 됨)을 누르면 그 부서 첫 빈 줄에, 같은 줄이 이미 있으면 안 넣음.
- **야간 그림**: 파일 고르기 또는 Ctrl+V → 화면에서 2400px·85% JPEG → [저장] 때 같이 보냄(`logSave`의 `night`, `'-'` = 빼기). 새 그림·시트를 다 쓴 뒤 옛 그림 휴지통. `logData_`가 그림을 data URI로 돌려줌(인쇄·PDF에 그대로).
