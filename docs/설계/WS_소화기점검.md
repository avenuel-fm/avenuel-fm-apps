#### 15.3.17 소화기 점검 (점검 메뉴의 하위 작업)

**1. 화면 흐름**
```
메인 → [점검] → [소화기 점검]
        ├─ 입력 기간 안내 (이번 달 1~5일 · 마감 임박 · 미입력 n)
        ├─ ① 소화기 QR 관리   검색 · ＋등록 · 출력(PC) · 삭제 · QR 크게 보기
        └─ ② 월별 점검 현황   ‹ 월 › · 범례 · 층 트리(B1~6F) → 층별 매장·소화기 → 누르면 입력 내용
QR 찍기 → 점검 입력 페이지 (로그인 없음)
```

**2. ① 소화기 QR 관리**
- 등록: 층(B1~6F), 매장명(이전 이름 자동완성), 대수(1~20). 이름은 `매장명-소화기1, 2…`로 이어 붙입니다.
- 삭제: `사용여부=N` + `삭제일시`. 삭제한 달까지의 현황에는 남고, 다음 달부터 빠집니다(그 달에 점검 기록이 있으면 그 달에는 남음).
- **출력은 PC에서만** 보입니다 (`(hover:hover) and (pointer:fine)` + 화면 폭 900px 이상). 휴대폰은 등록·삭제만.
- 출력 → **라벨 미리보기**(실제 mm 크기, 최대 6장 보이기) → 크기 버튼 `50×50(지금 라벨) · 40×40 · 30×34 · 50×30` 또는 직접 입력(15~100mm) → [1장 시험 인쇄] 또는 [인쇄]. 바꾼 크기는 인쇄할 때 `설정`에 저장됩니다.
- **프린터**: BIXOLON SLP-TX400, 203dpi(8점/mm), 라벨 50×50mm (결정 40). 미리보기 안 「BIXOLON SLP-TX400 인쇄 설정」 접이 안내(대상·용지 크기·여백 없음·배율 기본·머리글 끔·배경 그래픽 켬, 드라이버 용지 만들기, 갭 용지, FEED로 위치 맞추기).
- **QR을 점에 맞춤**: QR 칸 수(+여백 2칸)로 나눠 한 칸 = 프린터 점 정수 개(50×50이면 9점 ≈ 1.13mm)가 되게 그림 크기를 정함. `설정.프린터dpi`(기본 203)로 바꿀 수 있음.
- **라벨 모양**: 위에 `매장명 소화기N` 한 줄(7pt, 길면 줄여 최소 4.5pt), 아래에 QR(라벨 폭에 맞춘 정사각형). 층·안내 문구는 넣지 않습니다. `@page`를 라벨 크기로, 여백 0.

**3. QR**
- 내용: `{바로가기주소 또는 /exec}?fe={고유번호}` (14.1).
- 고유번호: **12자리**, 글자 `23456789abcdefghijkmnpqrstuvwxyz`(헷갈리는 l·o·0·1 제외, 60비트), 등록할 때 겹침 확인.
- 예전 32자리(hex)도 계속 열립니다. 시트 메뉴 **④ QR 고유번호 짧게 바꾸기**로 바꾸면 예전 QR은 안 열리므로 다시 인쇄합니다.
- 오류 보정 M, qrcodejs 1.0.0(cdnjs).

**4. QR 점검 입력 페이지 (매장 직원, 로그인 없음)**
- **어디서 열리나 (v0.3, 결정 42)**: QR 주소 `…github.io/fm/ws/?fe=…`를 열면 바로가기 페이지가 구글 웹앱을 띄우지 않고 **GitHub의 `fm/ws/check.html`을 직접 엽니다.** 구글 웹앱 화면(격리 iframe)은 카메라 권한이 막혀 있어 실시간 카메라 위에 원을 겹칠 수 없기 때문입니다.
  - 화면은 GitHub, 저장은 구글: `check.html`이 `GET {exec}?api=check&fe=…`로 소화기 정보를 받고, `POST {exec}`(본문 `{"action":"checkSubmit","qr","d"}`, `text/plain`)로 보냅니다. 응답은 JSON.
  - 쿠키 없이 부르므로 구글 계정이 여러 개 로그인된 휴대폰에서도 오류가 없습니다.
  - `check.html`은 `src/Check.html`에서 만들어 냅니다(같은 화면 코드, 통로만 다름). 화면을 고치면 GitHub 파일도 다시 올립니다.
  - 예전 `/exec?fe=` 주소로 열면 구글 웹앱 안 화면이 뜨고, 카메라는 기본 카메라 앱으로 대신합니다.
- **메뉴 (결정 170 → 224 → 230)**: 메뉴 이름 「소화기/소화전/공기호흡기 점검」, ① 「소화기/소화전/공기호흡기 QR 관리」, ② 매장별 소화기 점검 현황, ③ 층별 소화전/공기호흡기 점검 현황 (조회만 — 소화전·공기호흡기 입력은 QR로만)
- **수량 엑셀 올리기·내려받기 (결정 250)**: ② 매장별 점검 현황 첫 화면·층 화면에 [엑셀 올리기][엑셀 내려받기]. 양식 = 시트 이름이 층, 칸 NO · 브랜드명 · 소화기 개수. 올리면 미리보기(매장별 엑셀·지금·처리) 뒤 [등록하기]로 부족한 만큼만 QR 소화기 등록, 많은 것은 「초과」 표시만(삭제는 QR 관리 또는 층 화면 [소화기 삭제]), 엑셀에 없는 매장은 그대로.
- **층 목록 (결정 228·260)**: B3 ~ 10F, 맨 아래 **POPUP**(소화기·소화전·공기호흡기 공통). 엑셀 시트 이름 POPUP·팝업을 이 층으로 읽음.
- **층 화면 소화기 삭제 (결정 250)**: 층 화면 [소화기 삭제] → 소화기를 눌러 고르기(매장 [전체 선택]) → 확인 창 → `feDelete`. 지운 달부터 목록에서 빠지고 지난달까지의 점검 기록은 남음. 이번 달 점검을 입력한 소화기도 지워짐(결정 250, SQL 05·23 다시 실행). — ③④⑤와 소화전·공기호흡기 전부는 `WS_소화전공기호흡기.md`.
- **화면 모양 (결정 156)**: 공통 디자인(결정 150)을 따름. 남색 머리줄, 구역마다 구분선, 사진·손글씨 칸은 얇은 실선, 상태 버튼은 붙여서 고른 쪽을 남색으로 채움. 완료 표시는 이상 없음 = 테두리 ✓, 이상 있음 = 채운 !. 틀 이름에 `page`를 쓰지 않음(인쇄 양식 제외 규칙에 걸림). 카메라 화면은 공통 디자인 제외.
1. 소화기 이름·층·이번 달 입력 기간 표시. 기한이 지났으면 「기한 후 입력」 안내.
   - 사진 칸(찍기 전)은 **압력계 그림 + 그 아래 「사진 찍기」** 글자 (결정 52).
2. **압력계 사진**: 실시간 카메라 화면 위에 흰 원 가이드 + 「동그라미에 압력계를 맞춰 주세요」. 가운데를 4:3으로 잘라 **640×480 JPEG 60%(약 45KB)**. 카메라를 못 쓰면 기본 카메라 앱(`<input capture>`)으로.
   - **손전등 버튼** (결정 42): 카메라가 손전등을 지원하면 위 오른쪽에 🔦 버튼(켜기/끄기). 지원하지 않는 휴대폰(주로 아이폰)에서는 버튼을 숨깁니다. 카메라를 닫으면 꺼집니다.
   - **찍은 뒤 확인 화면** (결정 42): 찍은 사진 위에 같은 원을 흐리게 겹쳐 보여 주고 **[다시 찍기] [이 사진 쓰기]**. 기본 카메라 앱으로 찍은 사진도 같은 확인 화면을 거칩니다.
3. **상태**: 이상 없음 / 이상 있음.
4. **손글씨 칸 2개 위아래**: ① `외관·압력 이상무`(이상 있음이면 `이상 내용`) ② `이름`. 안내 글자는 **연회색(#C5CCD6) 굵은 글자**로 칸 가운데에 채워 보여 줌(결정 46, 예전 점선 글자는 잘 안 보여 바꿈). 저장은 손으로 쓴 획만 600px 폭 PNG.
5. 세 칸이 모두 채워져야 **[전송하기]**가 켜지고, 빠진 칸은 버튼 위에 빨간 글자로 알려 줍니다.
6. 이번 달에 이미 입력했으면 「바꿀까요?」 확인 후 덮어씀(`덮어쓴횟수` +1).
7. 끝 화면: 「점검이 저장되었습니다」.
- 보안: 고유번호가 맞고 `사용여부≠N`인 소화기만 열림. 사진·손글씨는 형식·크기 검사(서버 `parseDataUrl_`). 서버는 그 소화기 한 대의 이번 달 기록만 씀.

**5. ② 월별 점검 현황**
- 현황 화면을 열어 두면 **1분마다 저절로 다시 읽음**(화면이 보일 때만). 휴대폰에서 보낸 점검이 곧 반영됨 (결정 54).
- QR 입력 완료 화면에 **저장 번호**(`WS-FC-…`)와 입력 일시를 작게 표시 (결정 54).
- 상태 색: **점검완료 녹색 · 이상 있음 주황 · 점검 전 회색 · 미입력 빨강** (마감일이 지나고 기록 없음).
- 월 이동, 층 트리(층마다 완료/전체), 층을 누르면 매장별 소화기 목록, 누르면 사진·상태·손글씨·입력 일시·「기한 후」.
- `?api=summary` 할 일: 마감 임박(점검 전 n) · 미입력 n · 이상 있음 n → 소장·부소장·파트장.

**6. 저장**
- 드라이브: `시설팀 통합업무/20_업무지원/소화기점검/YYYY-MM/`
- 파일 이름: `YYYY-MM-DD_소화기점검-{소화기이름}_001.jpg`(압력계) · `_002.png`(문구) · `_003.png`(이름)
- ID: 소화기 `WS-FE-YYYYMMDD-###`, 점검 `WS-FC-YYYYMMDD-###` (4장 등록부)

**7. DB 탭 (`20_업무지원_DB`)**

**8. 서버 함수**
| 함수 | 권한 | 하는 일 |
|---|---|---|
| `feList(token)` | 로그인 | 소화기 목록 + QR 주소 + 라벨 크기 |
| `feAdd(token, {floor, store, count})` | 로그인 | 등록(번호 이어 붙임, 12자리 고유번호) |
| `feDelete(token, ids)` | 로그인 | 삭제 표시 |
| `labelSave(token, w, h)` | 로그인 | 라벨 크기 저장(15~100mm) |
| `feStatus(token, ym)` | 로그인 | 월별 현황·층별 숫자 |
| `feDetail(token, checkId)` | 로그인 | 입력 내용(사진·손글씨) |
| `checkInit(qr)` / `checkSubmit(qr, d)` | 없음(고유번호) | QR 입력 페이지 (구글 웹앱 안) |
| `GET ?api=check&fe=` / `doPost {action:"checkSubmit"}` | 없음(고유번호) | 같은 일을 GitHub `check.html`에 JSON으로 (v0.3) |
| 시트 메뉴 ④ `shortenTokensMenu_` | 시트 편집자 | 32자리 → 12자리 |
| 시트 메뉴 ⑤ `dataCheckMenu_` | 시트 편집자 | 날짜·숫자로 바뀐 칸·빈 필수 칸 찾기, 원하면 글자로 고쳐 씀 (결정 54) |

**9. 테스트판에서 단순화한 것 (정식판에서 바꿀 것)**
- 직원: 공통 DB 대신 이 시트의 `직원` 탭 → `cdb.staff()`
- 매장: DW 매장 목록 대신 직접 입력 → DW `매장` 탭 + `store_id`
- 문서색인·사진색인 기록 없음 → 정식판에서 `cdb.addDocs`(FC) · `cdb.addPhotos`
