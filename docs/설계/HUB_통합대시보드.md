### 15.1 HUB 통합 대시보드 v1.0
- **화면**
  - PIN 팝업 로그인 (PIN 변경 화면은 없음, 7.1)
  - 위 막대, 통합 검색창, 기준 연도·월·파트
  - **앱 카드**
    - DW: 협의중 · 7일 내 오픈 · 컨펌완료 · 방재실 협의서 미첨부. **소장·부소장만 활성**(숫자·할 일·누르면 DW 짧은 주소로 이동, DW는 자기 PIN으로 로그인 — 결정 36). 다른 역할에게는 「도면협의」 이름만 있는 **회색 비활성 카드**로 보이고 눌러도 열리지 않음 (7.4, 결정 32)
    - 카드의 이동 주소는 `앱목록`에 등록한 주소를 씀. DW 짧은 주소 `tinyurl.com/avenuel-dr`가 먼저 만들어져 있으므로 HUB를 만들 때 `앱목록`에 그대로 등록해 불러옴 (14.1)
    - WS: 오늘 일정 남음 · 결재 대기 · 하자 조치 대기 · 기한 지남
  - 역할별 할 일, 공지, 바로가기(짧은 주소, QR, 홈 화면 추가 방법)
- **관리**
  - **직원 관리** (7.5): 이름·PIN 미리 입력, 추가, 삭제(`사용여부=N`), PIN 다시 넣기. 입장표 `&view=staff`로 다른 앱에서 바로 열 수 있습니다. 입력 항목은 받은 뒤 확정합니다 (WS-3)
  - 파트, 앱 등록, 검색사전, 공지
  - **주소록 관리** (6.3): 롯데쇼핑 인원·그룹 추가, 고치기, 삭제, 「주소록 불러오기」(DW 시공업체·서명 이메일 가져오기)
  - 오류기록, 드라이브 용량, 메일 남은 수
  - 「검색키 다시 만들기」, `HUB_KEY` 교체 안내
- **예약 작업**: 매일 새벽 백업, 12월 1일 다음 해 색인 탭 만들기
