# 공통 디자인 현황 분석

- 작성: 2026-11-19 · 분석만 했고 **앱 코드는 고치지 않았습니다**
- 견본 그림: `docs/시안/공통디자인/공통디자인_견본.png`
- 기준 문서: `docs/설계/06_공통_디자인.md` (도면협의 `Styles.html`이 기준)

## 0. 어떻게 셌나

| 묶음 | 분석한 파일 |
|---|---|
| 도면협의(DW) | `apps/dw/src/Styles.html`, `App.html`, `Index.html` |
| 업무지원(WS) | `apps/ws/src/Styles.html`, `Index.html` |
| QR 점검 | `apps/ws/src/Check.html` |
| 지도 | `fm/map/css/*.css`, `fm/map/index.html`, `fm/map/js/**` (뷰어 3종은 따로 확인) |
| 바로가기 | `fm/index.html`, `fm/ws/index.html`, `fm/dw/index.html`, `fm/hub/index.html` |

- `fm/ws/app.html`·`fm/dw/app.html`·`check*.html`은 원본에서 자동으로 만들어진 판입니다. 색과 글자 크기 수가 원본과 같아 **중복으로 세지 않았습니다.**
- `fm/ws/spec.html`(시방서)·`fm/ws/eh-sb.html`(신고필증)도 업무지원 원본에서 만들어지므로, 업무지원을 고치면 같이 바뀝니다.
- 「회」는 코드에 적힌 횟수입니다. 화면에 보이는 횟수가 아닙니다.
- 화면용과 인쇄 양식의 구분은 부품 이름으로 나눈 것이라 **조금 틀릴 수 있습니다.** 3장의 표는 디자인 규칙에 적힌 값만 세었고, 코드 줄 안에 직접 적은 글자 크기(업무지원 69곳, 도면협의 11곳)는 빠져 있습니다.

**핵심**
1. 도면협의·업무지원·QR 점검·바로가기는 **기본 색이 같습니다.** 어긋남은 나중에 코드에 직접 적은 비슷한 색에서 생겼습니다.
2. **지도만 다른 디자인 계열입니다.** 파랑·회색·글꼴·버튼 크기가 모두 다릅니다.
3. 부품을 앱마다 복사해 쓰고 있어, 같은 이름의 버튼도 크기와 뜻이 다릅니다.
