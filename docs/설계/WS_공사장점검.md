#### 15.3.21 공사장 점검

**1. 화면 흐름**
```
메인 → [점검] → [공사장 점검]
  ① 오늘 순찰 카드: 「11월 11일 (수) 순찰 · 현장 n곳 중 n곳 점검」, 미흡 n건, 진행 막대
  ② 오늘 점검할 현장 (진행 중 공사 현장 전부)
       각 줄: 번호 · 현장명 · 공사 내용·업체 · 점검자 시각 · 결과 딱지(점검 전 / 양호 n / 미흡 n) · [PDF] · ⋯(고치기 · 공사 끝)
       관리자·소장만: [기본 항목 고치기 (n)]
  ③ [＋ 새 공사 현장 추가] → 현장 이름(층+매장) · 공사 내용 · 업체
  ④ 지난 점검: 날짜별로 현장 줄 (누르면 그날 점검 열기 · [PDF])
현장 누름 → 현장 점검
  - 위: 현장 · 공사 내용·업체 · 점검자(자동) · 점검 시각(자동)
  - 항목 카드: 이름 · 점검 기준 · [양호|미흡|해당없음] · 사진(4:3 칸, 한 줄 3칸 × 2줄 = 최대 6장, 찍은 시각 표시. 빈 칸 3개를 기본으로 보이고 3장을 넘기면 두 번째 줄에 「＋ 사진 추가」 — 11-11 v0.9.4) · 특이사항
    미흡은 빨간 테두리. 다시 누르면 고른 것 풀림
  - [＋ 이 현장에 점검 항목 추가] (이번 점검 이 현장만, [지우기] 있음)
  - 아래 막대: 미흡·양호·해당없음 셈 · 저장 상태 · [점검 끝 · PDF] (만든 뒤 [PDF 열기] · [PDF 다시])
```

**2. 저장 (결정 100)**
- **자동 저장**: 고친 뒤 1.5초, 사진은 고르면 바로. 한 번에 하나씩 보내 같은 사진이 두 번 올라가지 않음. 실패하면 「저장 못 함 · [다시 저장]」. 뒤로 가기는 저장을 마친 뒤 나감
- 한 점검 = 시트 `공사점검` 한 줄 (같은 날 같은 현장은 같은 줄). 항목·결과·메모·사진 id는 `항목` 칸에 JSON
- **점검자·점검 시각 = 처음 저장한 사람·시각**. 뒤에 다른 사람이 고쳐도 그대로, 고친 사람·시각은 `고친사람`·`수정시각`
- 사진: 기기에서 긴 변 1600px · 70% JPEG (03 9장). 이름 `YYYY-MM-DD_공사장점검-{현장}_###.jpg`, 번호는 지운 사진 번호도 다시 안 씀(`사진번호`). 뺀 사진은 시트를 쓴 뒤 휴지통(결정 80 순서). 화면이 보낸 사진 id는 그 점검의 사진일 때만 받음
- 폴더 `시설팀 통합업무/20_업무지원/점검/공사장점검/YYYY/YYYY-MM/`
- 날짜 = 근무일(오전 6시 경계, 결정 60). 지난 날짜 점검도 열어 고칠 수 있음

**3. PDF**
- 화면에서 만듦(html2pdf, TBM과 같은 방식, 05 11.1) → 서버 저장 → 「링크가 있는 사람 보기」 공유
- **날짜별 · 현장별 1개**: `YYYY-MM-DD_공사장점검-{현장}.pdf`. 다시 만들면 예전 PDF는 휴지통
- A4 세로, 여백 30px: 제목 「공사장 안전점검 보고서」, 표(현장·공사 내용·업체 / 점검자·점검 시각·결과), 항목 3칸 × 3줄(사진 칸 크기는 그대로: 1장 크게 · 2장 · 3~4장 2×2 · 5~6장 3×2, 자르지 않고 줄여 넣음, 없으면 「사진 없음」), 아래 출력 시각
- 결과를 안 고른 항목, 미흡인데 특이사항이 빈 항목이 있으면 만들기 전에 물어봄
- 저장 뒤 고치면 목록 PDF는 옛 판 (`stale`) — 다시 만들려면 [PDF 다시]
