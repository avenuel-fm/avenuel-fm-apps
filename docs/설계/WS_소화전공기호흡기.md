# WS · 점검 › 소화전 · 공기호흡기 점검

- 판: **v0.3 (메뉴 이름 변경 · 앱은 조회만, 업무지원 v0.25.2, 코드·시험 완료, 배포 전)** · 수정 2026-11-21 · 공통 규격 v1.3 — v0.1(v0.25.0)·v0.2(v0.25.1)은 배포됨
- 담은 장: 15.3.17 소화기 점검의 곁가지 (결정 224 · QR 관리 v2 결정 228 · 메뉴 이름·조회만 결정 230)
- **이럴 때 읽기**: 소화전·공기호흡기 등록·QR·점검 입력·층별 현황을 다룰 때. 소화기 자체는 `WS_소화기점검.md`.
- 목차·읽는 법: `docs/설계/00_목차_읽는법.md`

> **요약**
> - 메뉴 이름은 **「소화기/소화전/공기호흡기 점검」**(결정 230). 메뉴는 ① **소화기/소화전/공기호흡기 QR 관리** ② 매장별 소화기 점검 현황 ③ **층별 소화전/공기호흡기 점검 현황** 세 줄. **업무지원 앱에는 점검 입력이 없고(④⑤ 삭제) ③은 조회만** — 소화전·공기호흡기 **점검 입력은 붙어 있는 QR을 휴대폰으로 찍어 여는 화면(`eq.html`)에서만** 합니다.
> - 소화전·공기호흡기는 매장이 아니라 공용부 장비 → **층 + 위치를 직접 적어 등록**, 지도 고유번호(`AV-1F-0012`)에는 걸지 않음 (`WS_매장연동.md`와 겹치지 않음).
> - **등록 (결정 228)**: 한 창에서 종류(소화기·소화전·공기호흡기)를 **여러 개 체크**, 층 **B3~10F**, **위치**, 대수 → 이름은 모두 `위치-종류번호`(`동측 계단 앞-소화기1`·`-소화전1`·`-공기호흡기1`). QR 목록은 종류 탭마다 **층 → 위치 아코디언**.
> - 점검은 소화기처럼 **월 1회, 매월 1~5일 입력, 기한 뒤에도 받고 「기한 후」 표시**, 한 장비 한 달 1건(다시 보내면 확인 후 바꿈).
> - **점검자 = 앱에 로그인한 직원 이름 자동.** 손글씨 서명 없음. 항목마다 「정상/이상」 + 사진(필수) + 이상일 때만 한 줄 이상 내용(선택).
> - QR을 찍으면: **앱에 로그인한 상태 → PIN 없이 바로 입력**, **로그인 안 한 상태 → 입력 없이 지난 12개월 점검 표**(사진 없음, 점검자 이름 가림).

#### 2. 장비 등록 · QR 목록 (① QR 관리, 결정 224 → 228)
- **등록 창** [+ 등록]: **종류 체크박스**(소화기·소화전·공기호흡기, **여러 개 체크 가능**, 지금 보는 탭이 미리 체크) · **층** B3~10F(13개) · **위치**(직접 적기, 30자, 예: 동측 계단 앞) · **몇 대**(1~20, 체크한 종류마다 같은 대수). 아래에 「만들어지는 이름」 미리보기. 이름은 **`위치-소화기1`·`위치-소화전1`·`위치-공기호흡기1`**(층은 이름에 안 붙고 따로 표시).
  - 종류마다 차례로 등록(소화기 → `ws_fe_add`, 소화전·공기호흡기 → `ws_eq_add`). 중간에 실패하면 된 종류는 체크가 풀리고 실패 이유를 창에 알려 줌.
  - 번호는 **같은 종류·위치에서 지운 것까지 세어 이어서** 붙음(겹침 없음). 같은 위치에 한 대 더 만들면 번호가 이어짐.
  - 등록 뒤: 방금 만든 종류의 탭으로(지금 탭이 체크에 있으면 그대로), **그 층·위치가 펼쳐지고 새 항목이 미리 체크** → 바로 [출력].
- **목록**: 종류 탭마다 **층 아코디언(B3~10F 중 등록된 층만) → 위치 아코디언 → 항목**. 처음은 **모두 접힘**, 줄에는 `위치 n곳 · 소화기 m대` + **미인쇄 n**. [모두 펼치기]·[모두 접기]. 체크칸은 층·위치·항목 3단계(층 체크 = 그 층 전부, 일부만이면 가운데 표시). 출력·삭제는 체크한 것만.
- **위치 안 버튼**: **[+ 1대 추가]**(같은 층·위치에 한 대 더) · **[이름 고치기]**(그 위치 이름만 바꿈 → 안의 `-소화기1` 이름이 한꺼번에 바뀌고 **붙여 둔 QR은 그대로**, 지난 점검 기록의 이름도 맞춤. 같은 이름의 위치가 이미 있으면 안내).
- **미인쇄 딱지**: 아직 라벨을 인쇄하지 않은 항목에 표시. [인쇄]를 누르면 서버에 `printed_at` 기록(처음 한 번만) → 딱지가 사라짐. **1장 시험 인쇄는 인쇄함으로 치지 않음.** 열을 처음 만들 때 **지금까지 등록한 것은 인쇄한 것으로** 봄.
- **검색**: 위치·이름·층 글자가 들어간 것만 남기고 **맞는 층·위치는 자동으로 펼침**(눌러서 접으면 그대로), 지우면 접힌 모습.
- 삭제: `사용여부=N` + `삭제일시`. 삭제한 달까지의 현황에는 남음(그 달 점검 기록이 있을 때), 다음 달부터 빠짐 — 소화기와 같은 규칙. 지운 위치에 다시 등록하면 번호가 이어지고 새 QR.
- QR 고유번호 12자리(소화기·전열필증 고유번호와도 겹치지 않게). QR 주소 `{바로가기주소}?eq={고유번호}` → 바로가기 `index.html`이 `eq.html`로 보냄. 라벨 인쇄는 소화기와 같은 도구(BIXOLON SLP-TX400 50×50mm, 미리보기, 출력은 PC만), 라벨 글자는 이름 통째로.
- **옛 이름 이전**: 처음 판(v0.1)에서 만든 `3F 동측 계단 앞 소화전` 같은 번호 없는 이름은 `23_fire_equip.sql`을 다시 실행할 때 `동측 계단 앞-소화전1`로 한 번만 바뀜.
- 소화기의 칸 이름 「매장명」은 화면에서 모두 「위치」로 바뀜(DB 열 이름 `store_name`은 그대로). 이미 등록한 소화기 이름(`매장명-소화기1`)은 그대로.

#### 3. 점검 항목 (DB 함수 `ws_eq_spec`가 화면 셋이 같이 씀)
| 종류 | 항목 | 정상 / 이상 글 | 사진 |
|---|---|---|---|
| 소화전 | 외관 | 정상 / 이상 | 일반 사진 |
| | 누수 여부 | 누수 없음 / 누수 있음 | 일반 사진 |
| | 청소 상태 | 양호 / 불량 | 일반 사진 |
| 공기호흡기 | 충전량 | 정상 / 이상 | **압력계 사진** (동그라미 안내선) |
| | 압력조절기 | 정상 / 이상 | **압력계 사진** (동그라미 안내선) |
| | 외관 | 정상 / 이상 | 전체 사진 |
- 한 항목이라도 「이상」이면 그 점검은 **이상 있음**.
- 사진은 항목마다 **필수**(빠지면 저장 버튼이 안 켜지고 어느 항목인지 알려 줌). 압력계 사진은 소화기와 같이 실시간 카메라 + 손전등 + 확인 화면, **4:3 가운데를 잘라 640×480 JPEG 60%**.
- 이상 내용은 「이상」을 고를 때만 한 줄 칸(60자, 안 적어도 됨).
- 충전량 **숫자는 입력하지 않음**(사진만, 사용자 11-21).

#### 4. QR 입력 페이지 `eq.html` (원본 `src/Equip.html`, `tools/build_fm.py`가 만듦)
- **로그인 판정**: 같은 사이트 저장소의 `ws_token`(앱 로그인 표, 만료 전)이 있고 `ws_eq_open`이 받아 주면 로그인한 것. 사진 올리기에는 앱과 같은 기기 등록(`ws_sb_auth`)을 이어받음. 표가 틀렸거나 풀렸거나 기기 등록이 없으면 로그인 안 한 화면.
- **로그인 한 화면**: 위에 `점검자 홍길동 · 로그인 이름 자동`, 기한 후/이미 있음 안내. 항목 3개(정상/이상 + 사진). 저장 → 사진을 버킷 `equip/{QR}/연월/{무작위}.jpg`에 올린 뒤 `ws_eq_submit`. 이번 달 이미 있으면 사진을 올리기 전에 「바꿀까요?」 확인.
- **로그인 안 한 화면**: `ws_eq_pub` — 최근 12개월(장비 등록 달부터) 표: 월·입력일·기한 후, 항목별 정상/이상 칸, 이상 내용, 점검자(**`홍*동`처럼 이름 가림**). **사진 주소는 내려보내지 않음.** [앱에 로그인하기] → 돌아올 주소를 `sessionStorage.ws_after`에 적어 두고 `app.html`로. 앱은 로그인을 마치면(`afterLogin`) **같은 사이트의 `eq.html?eq=12자리`일 때만** 그 주소로 돌려보냄.
- 끝 화면: 저장 번호 `WS-EC-날짜-###`, 점검자, [업무지원 앱으로].

#### 4-1. 엑셀 개수 등록 · 이름 규칙 · 지도 심벌 (결정 296)
- QR 관리 › 소화전·공기호흡기 탭 [엑셀 올리기][엑셀 내려받기]. 양식: 시트 이름 = 층(B1F→B1), 칸 NO · 소화전 개수 · 공기호흡기 개수, 탭마다 그 종류 칸만 읽음. 미리보기(층별 엑셀·지금·처리) 뒤 부족분만 등록, 많은 것은 「초과」 표시만.
- 엑셀 등록 이름 = 층 + 종류 + 두 자리 번호(`1F소화전01`, `B1공기호흡기01`), 위치 = 층. 번호는 그 층·종류에서 비어 있는 가장 작은 번호(지운 번호 다시 씀). 손으로 [+ 등록]하는 것은 그대로 `위치-소화전1`.
- 지도 › 편집 › 심벌 추가/편집: 소화전·공기호흡기 심벌에 같은 규칙 이름이 붙고 심벌 아래에 보임(`symbolEditor.js` `symbolNextName`). 심벌과 QR은 따로 저장되므로 같은 층·종류의 번호로 짝을 맞춤.

#### 5. ③ 층별 현황 (앱 — 조회만)
- ③: ② 현황과 같은 모양. 층 행에 `소화전 n · 공기호흡기 n` + 미입력/이상 칩 + 완료/전체. 층을 누르면 소화전·공기호흡기 묶음별 위치 목록(점검자·입력 시각·기한 후), 누르면 항목별 정상/이상·이상 내용·사진 3장. 1분마다·돌아올 때 조용히 새로 읽음.
- **점검 입력은 앱에 없음 (결정 230)**: 예전 ④ 소화전 점검 입력·⑤ 공기호흡기 점검 입력 줄과 고르기 화면을 지움. ③ 화면에는 「이 화면은 조회만 됩니다. 점검 입력은 소화전·공기호흡기에 붙어 있는 QR을 휴대폰으로 찍어서 합니다.」 안내를 둠.
- 상태: **점검완료 · 이상 있음 · 점검 전 · 미입력**(마감일 지나고 기록 없음) — 소화기와 같은 칩.
- 메뉴 맨 위 알림(개선 제안 1): 이번 달 진행 `n / m곳`, 기한 지남이면 「미입력 n곳」 빨간 띠, 마감 하루 전이면 주황 띠. (메인 화면 타일은 서버 로그인 함수를 건드려야 해서 이번엔 하지 않음.)
- **점검 내용 팝업 · 점검 기록 삭제 (결정 290)**: 휴대폰은 화면에 꽉(제목·버튼 줄 고정, 가운데 스크롤), PC는 520px 그대로. 아래 [점검 기록 삭제] → 확인 → 그 달 기록만 삭제 표시(장비는 그대로) → 「미입력」, QR로 다시 입력. 로그인 직원 모두, 비로그인 불가(`ws_fe_check_delete`·`ws_eq_check_delete`).
