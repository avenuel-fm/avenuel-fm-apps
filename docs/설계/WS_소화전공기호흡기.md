# WS · 점검 › 소화전 · 공기호흡기 점검

- 판: **v0.1 (코드·시험 완료, 배포 전)** · 수정 2026-11-21 · 공통 규격 v1.3
- 담은 장: 15.3.17 소화기 점검의 곁가지 (결정 224)
- **이럴 때 읽기**: 소화전·공기호흡기 등록·QR·점검 입력·층별 현황을 다룰 때. 소화기 자체는 `WS_소화기점검.md`.
- 목차·읽는 법: `docs/설계/00_목차_읽는법.md`

> **요약**
> - 소화기 점검 메뉴가 ① **소화기·소화전·공기호흡기 QR 관리·인쇄** ② 매장별 소화기 현황 ③ **층별 소화전·공기호흡기 현황** ④ **소화전 점검 입력** ⑤ **공기호흡기 점검 입력**으로 늘어남.
> - 소화전·공기호흡기는 매장이 아니라 공용부 장비 → **층 + 위치 이름을 직접 적어 등록**, 지도 고유번호(`AV-1F-0012`)에는 걸지 않음 (`WS_매장연동.md`와 겹치지 않음).
> - 점검은 소화기처럼 **월 1회, 매월 1~5일 입력, 기한 뒤에도 받고 「기한 후」 표시**, 한 장비 한 달 1건(다시 보내면 확인 후 바꿈).
> - **점검자 = 앱에 로그인한 직원 이름 자동.** 손글씨 서명 없음. 항목마다 「정상/이상」 + 사진(필수) + 이상일 때만 한 줄 이상 내용(선택).
> - QR을 찍으면: **앱에 로그인한 상태 → PIN 없이 바로 입력**, **로그인 안 한 상태 → 입력 없이 지난 12개월 점검 표**(사진 없음, 점검자 이름 가림).

#### 1. 화면 흐름

```
메인 → [점검] → [소화기 점검]
        ├─ (맨 위) 소화전·공기호흡기 이번 달 n / m곳 · 기한 지남/마감 임박 알림
        ├─ ① 소화기, 소화전, 공기호흡기 QR 관리 · 인쇄   [소화기][소화전][공기호흡기] 탭
        ├─ ② 매장별 소화기 점검 현황                      (소화기, 기존)
        ├─ ③ 층별 소화전, 공기호흡기 점검 현황            월 이동 · 범례 · 층 트리 → 층별 위치 목록 → 입력 내용(사진)
        ├─ ④ 소화전 점검 입력        층·위치를 고르면 입력 화면(eq.html)이 열림
        └─ ⑤ 공기호흡기 점검 입력    〃
QR 찍기 → eq.html  ├ 로그인함  → 점검 입력 (점검자 자동)
                    └ 로그인 안 함 → 지난 점검 표 + [앱에 로그인하기]
```

#### 2. 장비 등록 (① QR 관리 › 소화전/공기호흡기 탭)
- 등록: **층**(B1~6F) + **위치**(직접 적기, 30자). 이름은 자동으로 `3F 동측 계단 앞 소화전`, `2F 방재실 1 공기호흡기`.
- 같은 종류에서 이름이 같으면 「이미 등록된 위치입니다」. 지운 위치는 다시 등록할 수 있고 새 QR이 만들어짐.
- 삭제: `사용여부=N` + `삭제일시`. 삭제한 달까지의 현황에는 남음(그 달 점검 기록이 있을 때), 다음 달부터 빠짐 — 소화기와 같은 규칙.
- QR 고유번호 12자리(소화기·전열필증 고유번호와도 겹치지 않게). QR 주소 `{바로가기주소}?eq={고유번호}` → 바로가기 `index.html`이 `eq.html`로 보냄.
- 라벨 인쇄는 소화기와 같은 도구(BIXOLON SLP-TX400 50×50mm, 미리보기, 출력은 PC만). 라벨 글자는 이름 통째로.

#### 3. 점검 항목 (DB 함수 `ws_eq_spec`가 화면 셋이 같이 씀)
| 종류 | 항목 | 정상 / 이상 글 | 사진 |
|---|---|---|---|
| 소화전 | 외관 | 정상 / 이상 | 일반 사진 |
| | 누수 여부 | 누수 없음 / 누수 있음 | 일반 사진 |
| | 청소 상태 | 양호 / 불량 | 일반 사진 |
| 공기호흡기 | 충전량 | 정상 / 이상 | **압력계 사진** (동그라미 안내선) |
| | 압력조절기 | 정상 / 이상 | **압력계 사진** (동그라미 안내선) |
| | 외관 | 정상 / 이상 | 전체 사진 |
- 한 항목이라도 「이상」이면 그 점검은 **이상 있음**.
- 사진은 항목마다 **필수**(빠지면 저장 버튼이 안 켜지고 어느 항목인지 알려 줌). 압력계 사진은 소화기와 같이 실시간 카메라 + 손전등 + 확인 화면, **4:3 가운데를 잘라 640×480 JPEG 60%**.
- 이상 내용은 「이상」을 고를 때만 한 줄 칸(60자, 안 적어도 됨).
- 충전량 **숫자는 입력하지 않음**(사진만, 사용자 11-21).

#### 4. QR 입력 페이지 `eq.html` (원본 `src/Equip.html`, `tools/build_fm.py`가 만듦)
- **로그인 판정**: 같은 사이트 저장소의 `ws_token`(앱 로그인 표, 만료 전)이 있고 `ws_eq_open`이 받아 주면 로그인한 것. 사진 올리기에는 앱과 같은 기기 등록(`ws_sb_auth`)을 이어받음. 표가 틀렸거나 풀렸거나 기기 등록이 없으면 로그인 안 한 화면.
- **로그인 한 화면**: 위에 `점검자 홍길동 · 로그인 이름 자동`, 기한 후/이미 있음 안내. 항목 3개(정상/이상 + 사진). 저장 → 사진을 버킷 `equip/{QR}/연월/{무작위}.jpg`에 올린 뒤 `ws_eq_submit`. 이번 달 이미 있으면 사진을 올리기 전에 「바꿀까요?」 확인.
- **로그인 안 한 화면**: `ws_eq_pub` — 최근 12개월(장비 등록 달부터) 표: 월·입력일·기한 후, 항목별 정상/이상 칸, 이상 내용, 점검자(**`홍*동`처럼 이름 가림**). **사진 주소는 내려보내지 않음.** [앱에 로그인하기] → 돌아올 주소를 `sessionStorage.ws_after`에 적어 두고 `app.html`로. 앱은 로그인을 마치면(`afterLogin`) **같은 사이트의 `eq.html?eq=12자리`일 때만** 그 주소로 돌려보냄.
- 끝 화면: 저장 번호 `WS-EC-날짜-###`, 점검자, [업무지원 앱으로].

#### 5. ③ 층별 현황 · ④⑤ 고르기 (앱)
- ③: ② 현황과 같은 모양. 층 행에 `소화전 n · 공기호흡기 n` + 미입력/이상 칩 + 완료/전체. 층을 누르면 소화전·공기호흡기 묶음별 위치 목록(점검자·입력 시각·기한 후), 누르면 항목별 정상/이상·이상 내용·사진 3장. 1분마다·돌아올 때 조용히 새로 읽음.
- ④⑤: 이번 달 장비를 층별로 나열(상태 칩), 누르면 `eq.html?eq=…&from=app`.
- 상태: **점검완료 · 이상 있음 · 점검 전 · 미입력**(마감일 지나고 기록 없음) — 소화기와 같은 칩.
- 메뉴 맨 위 알림(개선 제안 1): 이번 달 진행 `n / m곳`, 기한 지남이면 「미입력 n곳」 빨간 띠, 마감 하루 전이면 주황 띠. (메인 화면 타일은 서버 로그인 함수를 건드려야 해서 이번엔 하지 않음.)

#### 6. DB (`supabase/23_fire_equip.sql`, 05_fire·06_eh 다음에 실행, 두 번 실행해도 안전)
| 표 | 내용 |
|---|---|
| `fire_equip` | eq_id(`WS-EQ-날짜-###`), kind(`hyd` 소화전 · `air` 공기호흡기), floor, place, name, qr_token, active, created_at/by, deleted_at |
| `fire_equip_checks` | check_id(`WS-EC-날짜-###`), ym, eq_id, kind, floor, eq_name, state(이상없음/이상있음), items(jsonb: 항목·bad·memo·photo), **checker**(점검자 이름), entered_at, late, overwrite_count, deleted |
- 두 표 모두 RLS 켜고 **표 권한은 아무에게도 주지 않음**(함수로만). 주간 드라이브 백업 목록(`10_archive.sql`·`Archive.gs`)에 추가함 — 표 25개.
| 함수 | 권한 | 하는 일 |
|---|---|---|
| `ws_eq_list` · `ws_eq_add` · `ws_eq_delete` | 로그인 | 목록 · 등록(층·위치) · 삭제 |
| `ws_eq_status` · `ws_eq_detail` | 로그인 | ③ 현황(두 종류 한 번에) · 입력 내용(사진) |
| `ws_eq_open` | 로그인 | QR 입력에 필요한 값(점검자=내 이름, 항목, 이번 달 있는지) |
| `ws_eq_submit` | 로그인 | 저장(사진 경로 확인 `ws_eq_file`, 이미 있으면 덮어쓰기 확인) |
| `ws_eq_pub` | **비로그인도** | 지난 12개월 표(사진 없음·이름 가림) |
- 사진 올리기는 로그인 기기(`authenticated`)만 → 비로그인은 `equip/…` 경로에 못 올림. 소화기 QR 점검은 매장 직원이 로그인 없이 올리지만 이쪽은 로그인 필수.
- 파일 이름 `YYYY-MM-DD_소화전점검-{이름}_{항목키}.jpg`, 폴더 `소화전점검/YYYY-MM` · `공기호흡기점검/YYYY-MM`.
