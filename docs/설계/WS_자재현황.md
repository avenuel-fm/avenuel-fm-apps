# WS · 자재현황

- 판: **v0.0 초안 (결정 168 · 업무지원 v0.19.6)** · 수정 2026-11-19
- **이럴 때 읽기**: 메인 메뉴 「자재현황」 칸, 자재 입고·출고·재고 기능을 다룰 때
- 목차·읽는 법: `docs/설계/00_목차_읽는법.md`

> **요약**
> - 메인 메뉴 5번째 칸(「시방서 검색」과 「지도」 사이). 지금은 **「자재현황 · 준비중」** — 점선·회색, 누구도 눌러 열 수 없음 (결정 168).
> - 메인 메뉴 켜기·끄기(결정 148) 목록에는 **아직 넣지 않음**. 열 화면이 없으니 켤 것도 없음. 기능이 생기면 `MENU`에 `['stock', '자재현황', …]`을 넣어 다른 칸처럼 켜고 끔.
> - 본 기능은 아래 「정할 것」이 끝나고 시안을 확인한 뒤 만듦.

## 1. 사용자 답 (11-19)
| 질문 | 답 |
|---|---|
| 어떤 자재 | 정하지 않음 (아래 3장에서 다시 묻기) |
| 지금 양식 | **엑셀 파일** — 파일을 받으면 같은 칸 구성으로 만듦 |
| 입력·조회 | **직원 누구나 입력, 모두 조회** |

## 2. 처음 생각한 모양 (확정 아님)
- 목록: 자재 이름 · 규격 · 단위 · 현재 수량 · 보관 위치 · 최소 수량(이 밑이면 빨간 표시).
- 입고·출고: 자재를 고르고 수량·날짜·메모를 적으면 기록이 남고 현재 수량이 바뀜. 누가 적었는지는 로그인 이름으로 자동.
- 기록 보기: 자재별 입고·출고 내역, 월별 묶음.
- 자료는 다른 기능처럼 Supabase 표에 저장 (`supabase/` 새 SQL 파일). 처음 자료는 엑셀에서 한 번에 옮김.
- 화면은 공통 디자인(06 문서, 결정 150)을 따름.

## 3. 정할 것 (사용자에게 물을 것)
1. **엑셀 파일 받기** — 지금 쓰는 자재 대장 엑셀. 칸 이름과 자재 종류가 여기서 정해짐.
2. 자재 종류 나누기 (전기·설비·소방·건축 소모품 등) 필요 여부.
3. 출고할 때 **어디에 썼는지**(위치·작업) 적을지, 지도(결정 130)·QR과 이을지.
4. 수량 고치기(재고 조사)는 직원도 할 수 있는지, 소장·관리자만인지.
5. 엑셀로 내려받기 필요 여부.
6. 최소 수량 밑으로 내려가면 알림(카톡 등)까지 할지, 화면 표시만 할지.
