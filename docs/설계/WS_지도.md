## 1. 무엇을 하나
- 업무지원 메인의 6번째 칸(환경설정 바로 위, 전: 결재/내 서류 「작업중」)이 **「지도」**.

## 3. 자료 (Supabase)
- `map_kv` — 도면 앱이 브라우저에 두던 저장 칸을 **이름 그대로** 한 줄씩 (`k` = 옛 localStorage 이름, `v` = 글자, 고친 사람·시각).
  - 매장·기능실(`lotte_facility_specs_*`, `lotte_deleted_stores_*`, `lotte_renamed_stores_*`, `lotte_custom_stores_*`, `lotte_vacant_polygons_*`), 구역(`lotte_floor_zones_*`), 심벌(`lotte_symbols_*`), 설비 연결선(`lotte_util_lines_*`), 축척(`lotte_scale_settings*`), 고친 도면 그림(`lotte_saved_svg_*`).
  - 이름 끝 `_dept`·`_castle` = 백화점·캐슬플라자 (에비뉴엘은 없음).
  - 격자 간격(`lotte_grid_spacing_meters`)은 기기마다 보기 설정이라 브라우저에 그대로.
- `map_floor` — 층 도면 그림 주소 26개(에비뉴엘 7 · 백화점 16 · 캐슬 3). **공개 코드(`floors.js`)와 이 저장소(공개)에 두지 않음** — 11-17 배포 때 한 번 넣음. 원본은 옛 폴더 `C:\avenuel\lotte_map_handover\js\config\floors.js`의 `svgUrl`, 주 1회 백업 CSV에도 있음.
- 함수 (PIN 로그인 표 `ws_auth` 필수, 표는 화면이 바로 못 읽음):
  - `ws_map_load(표)` → `{ kv: {이름: 값}, urls: {건물: {층: 주소}} }` — 처음 열 때 한 번.
  - `ws_map_save(표, 이름, 값, 판)` → 한 칸 저장. 값 null = 지움. 이름은 `lotte_`로 시작하는 영문·숫자만, 값 5MB까지. 파트장 이상만. 판이 다르면 막음(8장).
- 고치면 그 칸을 바로 저장(칸마다 차례로). 실패하면 한 번 알림.
- 주 1회 백업 CSV에 `map_kv`·`map_floor` 포함 (`10_archive.sql`, `Archive.gs`).

## 7. 기록 · 되돌리기 (결정 132, 시안 `docs/시안/WS-지도기록/`)
- **기록 표 `map_hist`**: 저장할 때마다 같은 내용을 기록에도 한 줄. **같은 칸·같은 날은 마지막 것만** 남김 → 안 바뀐 칸은 기록 안 함 (작음).
- **기록 시작**: 배포 때 그때 모습을 **전날 기록**으로 한 번 넣음 → 배포 날 고쳐도 고치기 전 모습이 남음.
- **업체 바탕 도면 보관**: 층을 열 때 업체 그림을 받으면 sha256을 견줘 **바뀌었을 때만** 기록에 보관(`ws_map_base`, 누구나). 지난 날을 볼 때는 그때 보관한 그림으로 그림 → 업체가 그림을 바꿔도 옛 레이아웃·매장명을 봄. (보관 전 날짜는 지금 그림)
- **보기**: 지도 맨 위 **[기록]** → 달력(바뀐 날 파란 점, 기록 시작~오늘만 누를 수 있음) + 그달 바뀐 칸·고친 사람 목록. 날짜를 누르면 **그날 끝 모습**(`ws_map_at`, DB가 칸마다 그날까지 마지막 줄을 한 번에 찾음)을 「○월 ○일 기준 · 보기 전용」 띠와 함께. [오늘로 돌아가기].
- **되돌리기 (소장·부소장·파트장, 결정 214 — 전에는 소장만)**: 띠의 [이 날로 되돌리기] → 확인 창 → `ws_map_restore`가 지금 칸을 그날 모습으로(그날 없던 칸은 지움). `map_restore`에 기록, 되돌리기 **전 모습은 지우지 않음** → 달력 목록 「되돌리기 전 보기」로 다시 봄. 업체 바탕 도면은 되돌리지 않음(보기만).
- 용량: 글자 자료는 작고, 도면 그림(한 장 300KB 안팎)은 DB가 압축. 무료 500MB 안에서 몇 년.

## 8. 동시 편집 · 편집 권한 · Delete 키 (결정 134)
- **동시 편집**: 칸마다 판(`ws_ver(updated_at)`)을 받아 두고 저장 때 같이 보냄. 그사이 다른 사람이 같은 칸(층별 매장·구역·심벌·연결선 등)을 고쳤으면 서버가 저장하지 않고 「그사이 ○○님이 이 층을 고쳤습니다. 새로 불러옵니다.」 → 지도를 새로 불러옴 (방금 한 동작만 다시).
- **편집 권한**: 고치기 = 소장·부소장·파트장 (결정 136에서 관리자 뺌). 그 밖의 사람은 머리에 「보기 전용」, 편집·되돌리기(Ctrl+Z) 버튼 **꺼짐**(disabled, 결정 136), 고치려 하면 「지도는 소장·부소장·파트장만 고칠 수 있습니다」. 서버(`ws_map_can_edit`)도 막음.
- **Delete 키**: 연결선을 누르면 삭제 확인 창 → [취소]해도 **선택이 남아** Delete 키로 지움, Esc 로 선택 풀기 (인계 문서 5단계의 남은 버그).

## 12. 구역 그리기: 바닥 · 지우개 · 직각 (결정 216, 시안 `docs/시안/WS-지도바닥·지우개/`)

## 15. 배관 선 표시 · 간격 · 전기 붉은색 (결정 254)

- **전기 = 붉은색** `#dc2626`(선·레이어 메뉴 아이콘·새 선 색). 수도·가스·배수 색은 기존 그대로. 예전에 그린 전기 선도 CSS로 함께 붉게.

## 18. 복도 중심선으로 바닥 그리기 (결정 270)
- **쓰는 법**: 구역 추가/편집 → 「바닥」을 고르면 **🛤 복도 중심선** 버튼 · 폭 칸(기본 80px, 10~600) · 프리셋(주동선 80 · 일반 50 · 후방 35)이 나타남. 중심선을 켜고 클릭으로 점을 찍으면 폭만큼 양옆으로 펼친 반투명 띠가 마우스를 따라 보이고, Enter(또는 더블클릭)로 완료, Backspace 직전 점 취소, Esc 취소. 대각선 가능, Shift(또는 직각 체크)는 0·45·90도 단위로 고정. 바닥 열쇠(🔑)가 잠겨 있으면 그려지지 않음.

- **원인**: 지도 화면이 옛 `cad-tools.css`를 브라우저 기억에서 계속 써서, 고친 글자색(21장)이 안 보임.
