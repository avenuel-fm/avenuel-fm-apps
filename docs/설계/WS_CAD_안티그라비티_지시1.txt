CAD 도면 정리 도구 — 업무지원 앱 연동 규격 (Claude Code 세션이 정리, 사용자가 전달)

지금 만드는 「도면 정리 도구」(c:\avenuel\cad-viewer\cad-webapp-supabase\webapp)는 끝나면 업무지원 앱의 메인 「CAD」 칸 안에 붙습니다.
붙일 때 다시 고치지 않도록 아래 규격대로 만들어 주세요. 자세한 표는 저장소의 docs/설계/WS_CAD.md 에 있습니다.
기존 기능(DWG·DXF 열기, 레이어 분류·삭제, 맑은 고딕 변경, 용량 줄이기, 아이패드 터치)은 그대로 유지합니다.

[파일 자리]
- 완성본은 c:\avenuel\avenuel-fm-apps\fm\cad\ 폴더에 둔다 (index.html + js·css + DWG 해석기 wasm). 만들기 단계(빌드) 없는 정적 파일.
- 작업은 지금 폴더에서 해도 되지만 결과는 fm/cad/ 에 모은다. 그 밖의 폴더는 고치지 않는다(apps/ws, apps/design, fm/ws, fm/map, fm/thermal 등 읽기만).
- DWG 해석기(LibreDWG wasm)는 Supabase 버킷 cad-assets 에서 받지 말고 fm/cad/ 안 파일로 지연 로드한다(상대 경로).

[로그인·자료 — 가장 중요]
- 로그인 화면을 만들지 않는다. 업무지원이 PIN 로그인과 권한을 맡는다.
- Supabase 에 직접 붙지 않는다(config.js 의 주소·키, cad-assets 버킷, Edge Function 직접 호출 모두 쓰지 않는다). 자료는 모두 부모 창의 window.parent.WS_CAD 통로로만 주고받는다. 모두 Promise.
  · me() → { name, role }
  · boot() → { recent } (최근에 연 도면 기록 목록)
  · upload(blob, name) → { path, url } (원본·정리본 저장, 줄이지 않음)
  · saveRecord({ name, src_path, out_path, kept, fmt, date }) → { ok, id }
  · toDwg(dxfBlob) → { ok, blob } 또는 { ok:false, error } (DXF → DWG 변환. 업무지원이 로그인 확인 후 대신 호출)
  · toDrive(path, name) → { ok, url } (구글 드라이브, 나중 단계)
  · full(on) (화면 가득)
- 부모 창이 없으면(window.parent === window) fm/cad/mock_bridge.js 의 가짜 통로(브라우저 저장소, toDwg 는 「이 환경에서는 DXF 저장만」 오류)로 혼자서도 시험할 수 있게 한다.
- toDwg 가 없거나 실패하면 DXF 저장만 가능하다고 알리고 화면이 멈추지 않게 한다.
- 도면은 지금처럼 브라우저 안에서만 처리한다. 서버에 올리는 일은 upload() 를 사용자가 누를 때만.

[화면]
- 공통 디자인 apps/design/tokens.css 의 값(남색 #1E3A5F, 바탕 흰색, 모서리 2px, 버튼·입력칸 40px)을 쓴다. 이 파일은 고치지 않는다.
- 업무지원 창(iframe) 안에서 휴대폰(390px)·태블릿(아이패드)·PC 모두 쓸 수 있게. 가로 스크롤 없음.
- 자체 머리줄·뒤로 버튼은 만들지 않는다(업무지원이 왼쪽 아래 「뒤로」를 그림). 화면 가득이 필요하면 full(on).
- 글은 한국어, 사용자는 개발자가 아니므로 쉬운 말로.

[외부 라이브러리]
- cdnjs 같은 곳의 고정 판만 쓴다(최신 자동 판 금지). 가능하면 fm/cad/ 안에 넣는다.
