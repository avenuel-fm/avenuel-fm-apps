CAD 도면 정리 도구 — 방식 변경 지시 (지시1 대신 이 문서를 따릅니다. Claude Code 세션이 정리, 사용자가 전달)

[왜 바꾸나]
DWG 저장을 외부 변환 서비스(CloudConvert)로 하면 변환 한도(크레딧)가 닳고, 공개 키만 있으면 누구나 불러 한도를 소진시킬 수 있습니다.
그래서 「변환은 PC에서 오프라인 단독 프로그램」, 「온라인은 변환된 파일을 보기만」으로 나눕니다. 외부 변환 서비스는 쓰지 않습니다.

[만들 것 1: PC 단독 실행 프로그램 「CAD 변환기」]
- 기존 도면 정리 도구(c:\avenuel\cad-viewer\cad-webapp-supabase\webapp)의 기능을 그대로 가져온다: DWG·DXF 열기, 레이어 10개 분류·색, 레이어 선택 삭제, 모든 글꼴 맑은 고딕, 용량 줄이기, 밝게/어둡게, DXF 저장. 기존 코드를 최대한 재사용한다.
- Windows PC에서 **더블클릭으로 실행되는 단독 실행 파일(.exe)** 로 만든다(설치기 또는 단일 폴더 배포). Python 설치·서버 실행·인터넷 없이 돈다. 방식은 안티그라비티가 고르되(예: Electron/Tauri/PyInstaller) 이유를 한 줄로 알려 줄 것.
- Supabase·CloudConvert·Edge Function(dxf-to-dwg)·config.js 의 주소와 키는 **전부 제거**한다. 이 프로그램은 인터넷 없이 변환까지 끝낸다.
- DWG ↔ DXF 변환은 **PC에 설치된 변환 부품**을 불러서 한다(프로그램 안에 끼워 넣지 않는다).
  · 1순위: ODA File Converter 명령줄(무료). 설치 위치는 설정에서 고르게 하고, 없으면 「설치 안내」 화면(받는 곳 설명)을 보여 준다.
  · 대안: LibreDWG(dwg2dxf)는 DWG→DXF 읽기용. 두 부품 모두 쓸 수 있게 「변환 부품」 부분을 한 파일로 분리한다.
  · 한글 도면 인코딩(CP949), 글꼴 변경, 용량 줄이기 결과가 변환 뒤에도 유지되는지 실제 도면으로 확인한다.
- 폴더째 여러 도면 한 번에 변환(일괄)과 진행 표시를 넣는다. 실패한 도면은 이유를 한국어로 알리고 나머지는 계속한다.
- 결과: 뷰어용 DXF(필요하면 DWG도) + 작은 정보 파일(.json: 도면 이름, 층 이름, 레이어 수, 크기, 만든 날짜, 만든 사람). 저장 위치를 고르게 한다.
- 「업로드」 단추: 변환된 파일을 업무지원 서버로 올린다(아래 업로드 규격). 올리기 전에 대상 목록·크기를 보여 주고 사용자가 확인한 뒤 올린다.
  · 로그인: 업무지원 PIN(4자리)로 로그인해 받은 토큰으로 올린다. PIN은 저장하지 않는다.
  · 서버가 아직 없으므로 **가짜 서버 연결(mock uploader)** 로 시험할 수 있게 하고, 실제 서버 호출은 `uploader.js` 한 부품에 모은다.
  · 올린 뒤 결과(성공/실패, 목록에 보일 이름)를 알려 준다. 중복(같은 이름·같은 내용)은 「이미 있음」으로 알리고 덮어쓸지 묻는다.

[업로드 규격 초안 — 서버는 업무지원 쪽에서 나중에 만든다. 이름을 바꾸지 말고, 모르는 점은 질문으로 남길 것]
- login(pin) → { ok, token, name, role }
- upload({ token, name, floor, memo, dxfBlob, jsonInfo }) → { ok, id } 또는 { ok:false, error }  (파일은 구글 드라이브 「CAD 변환파일」 폴더, 목록은 표 cad_file)
- 올리는 권한: 소장·부소장·관리자. 보는 권한: 전 직원.

[만들 것 2: 온라인 뷰어 fm/cad/ (업무지원 화면 안 창, 열화상·지도와 같은 방식)]
- 완성본은 c:\avenuel\avenuel-fm-apps\fm\cad\ 에 둔다(index.html + js·css). 만들기 단계 없는 정적 파일. 그 밖의 폴더는 읽기만(apps/ws, apps/design, fm/ws, fm/map 등).
- **DXF만 열어 보는 뷰어**다: 이동·확대, 레이어 목록·켜기끄기, 분류색/원본색, 밝게/어둡게, 터치(아이패드·휴대폰). 편집·삭제·DWG 해석기(wasm)·변환은 온라인에 넣지 않는다(가볍게).
- 로그인 화면 없음. Supabase 직접 연결 금지. 자료는 부모 창의 window.parent.WS_CAD 통로로만(모두 Promise):
  · me() → { name, role }
  · list() → [{ id, name, floor, memo, by, date, size }]  (변환된파일 목록)
  · open(id) → { name, dxfBlob }  (파일 받기)
  · cacheGet(id) / cachePut(id, blob)  (한 번 연 파일은 이 기기에 보관해 다시 빠르게 엶 — 브라우저 IndexedDB, 업무지원이 아닌 뷰어가 직접 써도 됨)
  · full(on)  (화면 가득)
- 부모 창이 없으면(window.parent === window) fm/cad/mock_bridge.js 의 가짜 통로로 혼자 시험할 수 있게 한다(샘플 DXF 2~3개 목록).
- 첫 화면은 「변환된파일」 목록(이름·층·올린 사람·날짜·크기, 검색칸)이고, 누르면 도면이 열린다. 목록이 비면 「아직 올라온 도면이 없습니다」.
- 디자인은 apps/design/tokens.css (남색 #1E3A5F, 바탕 흰색, 모서리 2px, 버튼·입력칸 40px). 이 파일은 고치지 않는다. 자체 머리줄·뒤로 버튼 없음(업무지원이 그림). 가로 스크롤 없음, 390px 폰·아이패드·PC.
- 글은 한국어, 쉬운 말로.
