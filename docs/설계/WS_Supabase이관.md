## 2-1. 지금 규칙과 부딪히는 점 (참고)

1. **로그인**: 지금은 PIN 4자리 + 근무일 첫 서명(결정 56·60), 공용 휴대폰도 PIN만 바꿔 누름. Supabase Auth는 이메일·비밀번호(6자 이상)라 그대로는 PIN을 못 씀.
2. **파일 공개 여부**: 요청서의 「공개 URL」은 주소만 알면 로그인 없이 보임 → 「외부 접근 차단」과 어긋남. 초안은 비공개 버킷.
3. **서버 쪽 규칙이 화면으로 옮겨감**: PIN 잠금, 근무일 6시 경계, TBM 관리감독자, 엑셀 해석, 겹침 저장 확인 등이 지금은 서버(Code.gs)에 있음. 화면에서 DB를 바로 부르면 로그인한 사람은 누구나 표를 직접 고칠 수 있음(RLS가 「로그인했나」만 봄).
4. **QR 점검(`check.html`)**: 지금은 로그인 없이 고유번호로 열림(결정 42). RLS를 지키면 QR 화면도 로그인 필요.
5. **시트를 사람이 직접 보는 일**: 시트 메뉴(직원 등록·PIN 바꾸기), 위험성 목록 시트 편집, 종합업무일지 따로 시트(사용자 요청) → DB로 옮기면 시트로는 못 봄.
6. **진행 중인 세션 7개**: 같은 `Index.html`·`Code.gs` 를 고치는 중. 이관은 두 파일을 거의 새로 쓰는 일이라, 그동안 기능 수정을 멈추거나 따로 가지(branch)에서 해야 함.
7. **백업**: Supabase 무료판은 자동 백업이 없음 → 주 1회 이관 때 DB도 드라이브에 CSV로 떠 두는 것을 더하길 권함.
8. **밖에서 가져오는 것**(네이버 날씨·온습도 앱)은 브라우저에서 직접 못 부름(CORS) → Apps Script 정해진 시간 작업으로 남겨 DB에 써 넣음.

## 4. 3단계 계획 (11-14 초안, 사용자 확인 전)

### 4.1 화면을 어디서 여나 — **GitHub 바로가기 페이지에서 바로** (권함)
- 지금: TinyURL → `fm/ws/`(껍데기) → 구글 웹앱(`/exec`)을 안에 띄움. 구글 웹앱이 뜨는 데만 2~4초.
- 바꾼 뒤: `fm/ws/`가 **앱 자체**. 구글 웹앱을 거치지 않으므로 첫 화면이 빨라지고, QR 점검(`fm/ws/check.html`)과 로그인이 한 주소에서 이어짐(공용 계정 로그인을 한 번만).
- TinyURL·QR 주소는 그대로. 옛 구글 웹앱(`/exec`)은 지우지 않고 남겨 **되돌리기용**으로.

### 4.2 로그인 흐름
1. 처음 한 번: 「기기 등록」 화면에서 시설팀 공용 계정 이메일·비밀번호 → Supabase 로그인(기기에 기억, 자동 연장).
2. 그다음 매번: 지금과 같은 PIN 4자리 → 근무일 첫 로그인이면 서명 (결정 56·60 그대로).
3. PIN 잠금(30번/10분, 3번째부터 1시간)·근무일 6시 경계·서명 확인은 **DB 함수**로(화면에서 못 건너뛰게).
4. 「기기 등록 풀기」(공용 계정 로그아웃)는 환경설정 맨 아래, 관리자·소장만.

### 4.3 코드를 바꾸는 방식 — 통로 하나만 갈아 끼움
- 화면(`Index.html`)은 모든 서버 일을 `call(이름, …)` 하나로 부름 → 이 `call`을 Supabase로 바꾸는 **새 파일 `ws-api.js`** 를 만들어, 서버 함수 41개를 **같은 이름·같은 답 모양**으로 다시 만듦. 화면 코드는 되도록 그대로 → 실수가 줄고 다른 세션 수정도 옮기기 쉬움.
- 여러 표를 한 번에 고쳐야 하거나 규칙이 중요한 일(PIN·서명·TBM 저장·명일 저장 겹침 확인·직원 관리)은 **DB 함수**(SQL `02_functions.sql`)로, 나머지 읽기·쓰기는 `supabase.from(...)`으로.
- 엑셀 읽기(출근현황·전열필증)와 PDF 만들기는 지금도 화면에서 하므로 그대로.

### 4.4 파일 올리기
- 사진: 올리기 직전 화면에서 **가로 1200px 이하 · JPEG 80%** 로 줄임 (지금은 1600px·70% 등 업무마다 다름 → 하나로). 서명 그림(PNG)·PDF·엑셀은 그대로.
- 경로: `ws-files/{업무}/{YYYY-MM}/{무작위}.jpg` (영문만), 한글 이름은 `files.file_name`.
- 올린 뒤 공개 주소를 `files.file_url` 에, 업무 표에는 `files.id`.

### 4.5 구글 Apps Script에 남는 일
- 매일 13시 네이버 날씨, 온습도 앱 가동시간 읽기, 매일 3시 서명 정리 → 결과를 Supabase에 씀(service_role 키, 스크립트 속성).
- HUB용 `?api=summary` → Supabase에서 읽어 답함.
- 5단계 주 1회 드라이브 이관 + DB 백업(CSV).
