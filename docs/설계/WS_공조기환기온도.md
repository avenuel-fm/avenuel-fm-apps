  - 아래 고정 줄 (결정 176): [‹ 뒤로] · 저장 상태 · [인쇄 (B4)] · **[저장 ⇄ PDF 보기]**. [저장] = 고친 칸 저장 + PDF 만들기, 끝나면 [PDF 보기].

## 입력 칸 검사 (결정 178, 11-20)
- 칸 검사: 숫자 아니거나 범위 밖(환기 −10~50·외기 −30~50·습도 0~100·냉수 −5~40)이면 입력하는 즉시 칸을 빨갛게, 저장을 누르면 서버에 안 보내고 그 칸으로 이동·이유를 아래 줄에 남김(알림만으로는 놓침). 「22,5」「22.5℃」는 자동으로 「22.5」. [인쇄 (B4)]는 저장 안 한 값이 있으면 먼저 저장. 저장하는 사이 더 넣은 값은 지우지 않고 「저장 안 함」으로 남김.
- 이유: 김종우 PC에서 「저장 안 함」이 남음 — 서버는 한 칸이라도 틀리면 저장 전체를 거절하는데 경고가 2~3초 만에 사라지고 어느 칸인지 표시가 없었음.
