## 1. 무엇을 하나
지금 있는 매장·기능실, 직접 그린 매장, 앞으로 만들 매장·기능실에 **도형에 묶인 고유번호**를 붙이고, 상세내역을 **엑셀로 한 번에** 넣는다. 에비뉴엘·백화점·캐슬플라자 모두 같은 규칙.

## 2. 고유번호 규칙 (사용자 지정)
| 일 | 고유번호 | 매장명 | 상세내역 |
|---|---|---|---|
| 매장명을 바꿈 | **그대로** | 새 이름 | **그대로 이어받음** |
| 매장명만 지움 | **그대로** | 빈 칸 (「이름 없음」으로 표시) | **그대로 이어받음** |
| 도형을 삭제 | **함께 삭제** (다시 쓰지 않음) | 함께 삭제 | 함께 삭제 |
| 도형을 새로 그림 | **새 번호** | 새로 입력 | 빈 칸 |

- 모양: `AV-1F-0012` (건물 `AV`·`DP`·`CS` – 층 – 층마다 늘어나는 번호). 지운 번호는 다시 쓰지 않는다.
- 도형 삭제는 **사람이 [도형 삭제]를 눌렀을 때만**. 업체가 도면 파일을 바꿔서 도형을 못 찾는 경우는 삭제가 아니다 → 위치(중심 30 이내)·크기(20% 이내)로 다시 찾고, 그래도 못 찾으면 「확인 필요」 목록에 남긴다.
- 도형이 없는 글자(안내 문구 등)는 번호를 받지 않는다. 한 도형에 글자가 여럿이면 글자마다 번호를 주고 「확인 필요」에 보여 주며, 그 도형을 삭제하면 글자도 함께 지운다.

## 3. 엑셀 양식
- **건물마다 파일 1개, 층마다 시트 1개.** 시트 이름 `B1층`, `1층` … 으로 층을 찾는다. 파일을 올리면 **지금 보고 있는 건물**에 넣는다.
- 머리글 2줄: 1줄 묶음(`차단기`), 2줄 세부(`일반`·`비상`·`from`). 병합 안 된 칸은 1줄이 항목 이름(`급수`·`배수`·`가스`). 차단기에 `to` 칸은 없다.
- `순번`은 읽지 않는다. `매장명`으로 그 층의 도형을 찾는다.
- **항목 추가**: 엑셀에 열을 더해 다시 올리면 그 건물의 상세 항목으로 추가되어 상세·수정 창에 나온다. 열을 뺀 파일을 올려도 **있던 항목·값은 지우지 않는다**.

### 올릴 때 규칙 (사용자 확정 11-19)
| 경우 | 처리 |
|---|---|
| 이름이 도형과 맞음 | 그 도형(고유번호)에 저장 |
| 도면에 없는 이름 | **저장 안 함**, 확인 창에 목록 |
| 같은 층에 같은 이름 도형이 여러 개 | 엑셀 1줄이면 **모두 같은 값**, 여러 줄이면 고유번호 순서대로, 도형보다 많은 줄은 저장 안 함 |
| 엑셀에 없는 매장 | 그대로 둠 |
| 빈 칸 | 그 값을 **비움** (확인 창에 표시) |
| 매장명 변경 | 엑셀로는 안 함 — 지도 수정 창에서 |

- 저장 전 **확인 창**(시안 3)에서 바뀌는 내용을 보여 주고, [저장]을 눌러야 들어간다. 이름이 맞는 줄이 절반도 안 되면 다른 건물 파일일 수 있다고 알린다. 5MB 넘는 파일은 받지 않는다.
- 올리기 뒤에는 되돌리기(↶) 내역을 비운다. 올리기 전 모습은 날짜별 기록에 남는다.
- [엑셀 받기]: 지금 자료를 같은 양식으로 내려받음 → 고쳐서 다시 올림. 이름 없는 도형은 빠진다.
- 권한: 보기·받기 = 지도를 열 수 있는 사람, 올리기·고치기 = 소장·부소장·파트장·옵저버 (결정 136·138).

## 4. 자료 (표를 새로 만들지 않음)
기존 저장 칸 `map_kv`에 넣어 **날짜별 기록 · 되돌리기 · 동시 편집 막기 · 권한을 그대로 씀**. SQL 변경 없음.
- `lotte_store_book_{층}{_dept|_castle}` = `{ next: 13, items: { "AV-1F-0012": { shape, name, type, color, details: { "차단기|일반": "50" }, x, y, w, h, lost? } }, deleted: [도형값…] }`
- `lotte_store_items{_dept|_castle}` = 건물의 상세 항목 순서 `[{ g: "차단기", l: "일반" }, …]`. 저장 전에는 기본 6개.
- `shape` = 업체 도형 고유값(없으면 좌표), 직접 그린 매장은 `c_…`(예전 매장은 `c:번호`). 기능실은 `type: "utility"`로 같은 표.

## 5. 지금 자료 옮기기 (배포 뒤 자동)
- 고칠 수 있는 사람이 **층을 처음 열 때** 그 층의 번호를 만든다. 엑셀 받기·올리기를 누르면 아직 안 열린 층도 차례로 열어 만든다. 보기 전용인 직원은 만들지 않는다.
- 조사 결과 (11-19, 업체 도면 26개 층): 매장 글자 1,336곳 (에비뉴엘 255 · 백화점 1,018 · 캐슬 63), 그중 도형 없는 글자 43곳은 번호 없음.
- 실제로 저장된 상세내역은 그대로 옮긴다 (차단기→`차단기 일반`, 수도·급수→`급수`, 배수, 가스, 그 밖의 이름은 추가 항목). 이미 지운 매장은 번호를 주지 않는다.
- 지금 상세 창의 `3P 50A` 같은 **자동으로 지어낸 값**은 없애고 빈 칸으로 보여 준다.
