## 1. 작성기 (PC 프로그램, `apps/thermal-reporter/`)
- 넣는 것: FLIR 열화상 사진(.jpg, 이름 예 `1층1번_일반.jpg`), 보고서 제목, 측정자, 날짜.
- 하는 일: 사진마다 점 3개(R·S·T상) 자동 배치 → 온도·상간 온도차(ΔT). 점은 화면에서 끌어 옮김. 예전 보고서(.atr)로 점 위치 학습.
- 나오는 것: FLIR Thermal Studio 보고서(.atr). 양식은 `templates/master_template.atr`(2026년 4분기 EPS 1층).
- 실행: FLIR Thermal Studio 부품(`engine/` DLL, 약 385MB)이 있는 윈도우 PC에서 `run.bat` → `http://127.0.0.1:8765`. 파이썬 필요.
- 휴대폰·태블릿·구글 웹앱에서는 직접 열 수 없음 (이 PC에서만 열림).

## 2. 작업 방식 (사용자 11-19)
- 작성기 코드는 **안티그라비티**가 고치고, Claude Code 세션([점검]-[열화상점검])이 할 일을 정리해 지시문을 쓰고 결과를 검사함.
- 저장소에 올릴 때 `engine/` FLIR 부품·`temp/` 사진은 빼야 함 (FLIR 사용 허락·용량). 작성기는 아직 저장소에 없음.

## 3. 웹 전환 · 업무지원 연동 규격 (준비, 11-19)
사용자 11-19: 작성기를 PC 프로그램 → 웹에서 단독 실행으로 바꾸는 중(안티그라비티). 자료는 Supabase, 만든 파일은 PC로 내려받기 또는 구글 드라이브로. 끝나면 업무지원에 붙임. 붙일 때 다시 고치지 않도록 아래 규격으로 만듦. **지도(결정 130)와 같은 방식.**

| 항목 | 정한 것 |
|---|---|
| 파일 자리 | `fm/thermal/` (`index.html` + 필요한 js·css). 만들기 단계 없는 정적 파일. 파이썬 서버·`engine/` FLIR 부품 없이 브라우저에서만 |
| 여는 법 | 업무지원 [점검 › 열화상점검]이 `../thermal/index.html`을 화면 안 창(`iframe`)으로 띄움. 주소창은 업무지원 그대로, 「뒤로」는 업무지원이 그림 |
| 로그인 | 작성기에는 로그인 없음. 업무지원 PIN 로그인을 그대로 씀. 권한(소장·부소장·관리자·옵저버)은 업무지원이 거름 |
| 자료 통로 | 작성기는 Supabase에 **직접 붙지 않고** 부모 창의 `window.parent.WS_THERMAL`만 부름 (지도 `WS_MAP`과 같음). 업무지원이 PIN 로그인 표로 `ws_thermal_*` 함수를 부름 → 공개 키로 표를 열어 두는 일 없음 |
| 단독 시험 | 부모가 없으면(`window.parent === window`) `fm/thermal/mock_bridge.js`의 가짜 통로로 돎 (브라우저 저장소). 실제 자료는 안 씀 |
| 내려받기 | `.atr`는 브라우저에서 zip으로 만들어 바로 내려받음. 라이브러리는 cdnjs 고정 판(예: JSZip 3.10.1) |
| 구글 드라이브 | 2단계. 업무지원 구글 서버(`WS_GAS_URL`)가 드라이브 폴더에 넣음 — 작성기는 `WS_THERMAL.toDrive()`만 부름 |
| 디자인 | 공통 디자인 `apps/design/tokens.css` 값 (결정 150). 바탕 흰색, 남색 `#1E3A5F` |
| 화면 크기 | 업무지원 창 안에서 휴대폰(390px)·태블릿·PC 모두. 넘치는 가로 스크롤 없음 |

**`WS_THERMAL` 통로 (업무지원이 만듦, 모두 Promise)**
| 이름 | 하는 일 | 돌려주는 것 |
|---|---|---|
| `me()` | 지금 로그인한 사람 | `{ name, role }` |
| `boot()` | 처음 열 때 한 번 | `{ model, template_url, reports }` — 점 위치 학습 값, 양식 .atr 주소, 최근 보고서 목록 |
| `saveModel(model)` | 점 위치 학습 값 저장 (JSON) | `{ ok }` |
| `saveTemplate(t)` | 양식 .atr 바꾸기: `upload()` 결과에 `name`을 붙여 넘김 `{ path, url, name }` | `{ ok }` |
| `upload(blob, name)` | 사진·양식·보고서 파일 올리기 (Storage `ws-files/thermal/…`). **줄이지 않고 원본 그대로** (줄이면 온도 자료가 사라짐), 확장자는 `name`에서 | `{ path, url }` |
| `saveReport(r)` | 만든 보고서 기록 `{ title, inspector, date, path, pdf_path, pdf_url, drive_url, pages, max_dt }` — `.atr`(path·url) 또는 PDF(pdf_path·pdf_url) 중 하나는 있어야 함 | `{ ok, id }` |
| `toDrive(path, name)` | 서버에 올린 PDF를 구글 드라이브 `시설팀 통합업무/20_업무지원/열화상점검/연-월`로 복사 (구글 웹앱 `?api=thermaldrive`, 결정 182). 같은 PDF는 한 파일, 「링크가 있는 사람 보기」 | `{ ok, url }` |
| `full(on)` | 화면 가득 켜기·끄기 | — |

## 3-1. 작성기 웹판 검사 (11-20, 업무지원 v0.20.3)
- 위치 `fm/thermal/` (`index.html`·`app.js`·`flir_parser.js`·`atr_generator.js`·`spot_model.js`·`mock_bridge.js`·`styles.css`). 파이썬·FLIR 부품 없이 브라우저만. 라이브러리 pako 2.1.0·JSZip 3.10.1(cdnjs).
- 양식 `master_template.atr`(약 6.9MB, 건물 설비 사진 포함)은 **공개 저장소에 올리지 않음** (`.gitignore`). 소장이 처음 한 번 올리면 Supabase `thermal_kv.template`에 저장, 이후 `boot().template_url`로 받음. 못 받으면 「양식 파일 선택」 안내.
- 시험(11-20): 업무지원 창(iframe)에 넣고 가짜 통로로 — 양식 없음 안내 → 양식 올리기(`upload`+`saveTemplate`) → 사진 3장 → .atr 다운로드 + `upload`·`saveReport`(3쪽, 최대 ΔT) 호출 확인. 만든 .atr: 사진 칸 3개, 측정자·날짜 들어가고 옛 이름·옛 날짜 없음, zip 이상 없음.
- 온도 비교(옛 FlirTool vs 브라우저, 같은 위치): 2장은 소수 첫째 자리까지 같음, **1장은 0.6℃ 낮게 나옴**(28.9 ↔ 28.3 — 방사율·반사온도·거리 값 적용 차이로 추정). 사진에 점이 없던 5장은 위치가 달라 비교 못 함. → 4장 남은 일.

## 3-2. PDF 저장·드라이브 백업·뒤로 버튼 (11-20, 결정 182, 업무지원 v0.20.4)
- 작성기 버튼은 「PDF 저장」(저장되면 「PDF 보기」로 바뀜) · 「내려받기」(.atr) 두 개. PDF는 서버(`ws-files/thermal/…`)에 올린 뒤 `toDrive`로 드라이브에 백업. 작성기 수정은 안티그라비티 지시 3 (`WS_열화상점검_안티그라비티_지시3.txt`).
- 구글 웹앱 `?api=thermaldrive&path=…&name=…`: `thermal/연-월/<32자>.pdf` 모양만 받고(PDF 머리글 확인, 20MB 제한), Supabase에서 서비스 열쇠로 받아 드라이브에 복사. 이름의 특수문자는 정리. 같은 파일을 다시 누르면 새로 만들지 않음. 키 없이 열려 있지만 업무지원 PDF 보기(`?api=pdf`)와 같은 방식(이미 공개 주소인 파일만).
- `thermal_report`에 `pdf_path`·`pdf_url`·`drive_url` 칸 추가, `.atr` 없이 PDF만 있는 기록 허용 (`16_thermal.sql` 다시 실행하면 칸이 더해짐, 기록은 그대로).
- 뒤로 버튼: 작은 것(지도식)과 아래 긴 것이 둘 다 나오던 것을 아래 긴 것 하나로. 작성기 창은 긴 뒤로 줄 위에 맞춰져 가려지지 않음.

## 3-3. 작성기 수정 검사 (11-20, 안티그라비티 지시 3 결과 + Claude 고침)
- **온도**: 시험 사진 8장(`apps/thermal-reporter/samples/`) 모두 스팟 위치·온도가 옛 FlirTool 값과 **소수 첫째 자리까지 같음**(0.6℃ 차이 해결: 방사율·반사온도·거리·대기 투과율 반영). 단, 8장 모두 같은 카메라 한 종류다. 다른 카메라·설정 사진은 FLIR Thermal Studio와 비교 필요. 사진에 적용값이 없으면 방사율 1·거리 0m로 읽혀 그대로 계산함.
- **스팟 위치**: 사진 안 스팟 기록의 두 가지 모양을 읽음(8장 모두 인식). `.atr`로도 학습 가능(8장 학습 확인). 스팟이 없는 사진은 학습 못 했다고 알림. 사용자가 학습에 넣어 본 9장은 아직 못 구해 시험 못 함 (`samples/learn/`).
- **PDF 저장 → PDF 보기 → 고치면 되돌아옴 → 내려받기(.atr)** 동작, 업무지원 창 안에서 가짜 통로로 확인(PDF 서버 저장 → 드라이브 백업 호출 → 기록).
- **Claude가 고친 문제 4가지**: ① PDF가 **빈 종이**로 나옴(변환 도구가 화면 밖/고정 위치 요소의 높이를 0으로 잼 → 1px 겉 상자에 담음) ② PDF 오른쪽이 잘림(폭 780→720px) ③ **열화상 그림이 화면·PDF에 안 나옴**(사진 파일을 두 번째 JPEG 앞에서 잘라 쓰던 것을 파일 전체로, 실화상은 안에 든 가장 큰 JPEG를 JPEG 구조대로 끝까지 잘라 열리는지 확인, 없으면 열화상 그림으로 대신) ④ 적용값 글자에 「undefined℃」(이름 불일치) · PDF 기록이 실패해도 PDF는 저장됐으니 보기로 바꾸고 알림만.
- 아직 사람이 확인할 것: FLIR Thermal Studio로 .atr 열기(스팟이 옮긴 자리에 보이는지, 온도, 쪽 수), 휴대폰에서 PDF 저장·보기, 실제 구글 드라이브에 파일이 생기는지.

## 3-4. .atr가 안 열리던 문제 · 실화상 끊김 (11-21)
- **.atr가 FLIR에서 안 열림**: 보고서 제목을 바꾸면 문서·cactus-meta 안의 글자 **길이 칸**(`04 LL LL`, 그리고 경로 `C:\…\<제목>.atr` 앞 길이 칸)을 안 고쳐서 문서가 어긋났음. 제목이 기본값 그대로면 길이가 같아 열렸음. → 제목 글자와 모든 길이 칸을 함께 바꾸고, 전수 길이 검증 함수 추가(안티그라비티 지시 4). Claude가 제목 짧게(8B)·길게(101B)·같은 길이(24B)로 만든 .atr의 길이 칸을 직접 검사해 모두 맞음 확인.
- **실화상이 위쪽만 보이고 아래는 회색**: FLIR 사진은 FLIR 자료가 65KB 조각(APP1)으로 나뉘어 들어 있어, 파일을 그대로 잘라 쓰면 조각 머리글 때문에 그림이 중간에서 끊김. → FLIR 조각을 이어 붙인 자료 안에서 실화상(JPEG)을 찾도록 수정(Claude, `flir_parser.js`). 사용자 실제 사진·시험 사진 모두 전체가 나옴.
- 사용자 확인 남음: FLIR Thermal Studio로 .atr 열기(`apps/thermal-reporter/samples/atr_test/` A~D 4개 + 앱에서 만든 것).

## 3-5. .atr 안 내용이 양식의 옛 내용이던 문제 (11-21, 안티그라비티 지시 5)
- 원인: 문서 파일 안 **쪽마다 사진 사본 4장**(스팟 표시 PNG 690×517 · 실화상 2048×1536 · 열화상 320×240 · 잘라낸 실화상 320×240)과 **표 글자**(측정대상·Point 1~3 온도·온도차)가 들어 있는데 작성기는 보관함(`cactus/<guid>.bin`)의 사진만 바꿨음. FLIR는 문서 안 사본·글자를 보여 줌.
- 수정: 쪽마다 사본 4장을 새 사진으로 만들어 넣고(스팟 PNG·잘라낸 실화상은 화면에서 그림), 그림 앞 4바이트 길이 칸·표 글자를 새 값으로 바꿈. 길이 칸 전수 검사 통과.
- Claude 검사(11-21): 3쪽·10장(앞 8쪽) .atr — 문서 안 사진 길이 칸·그림 열림·온도 글자(첫 사진 32.3/29.9/26.0 일치)·회로 이름·제목 길이 칸 정상.
- **미확인(사람만 가능)**: FLIR Thermal Studio에서 열었을 때 쪽 사진·글자가 새 내용인지, 열리는지. FLIR 왼쪽 쪽 미리보기(작은 그림 170×240 5장)는 양식 것이 남아 있을 수 있음. 확인 파일 `apps/thermal-reporter/samples/atr_test2/` A(옛 PC 방식)·B(연결 유지)·C(사본·글자 교체).
