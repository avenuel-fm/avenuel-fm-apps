[1. 「내려받기」로 만든 .atr 가 FLIR Thermal Studio 에서 안 열림 — 원인을 찾았다]
확인한 사실 (사용자가 실제로 받은 c:\Users\Administrator\Downloads\EPS 1층.atr 와 양식 templates\master_template.atr 를 바이트 단위로 비교):
 · zip 구조·[Content_Types].xml·cactus-meta·MT.bin 의 FileSize·사진 파일은 모두 정상이고, FLIR 공식 부품(Cactus.Reporting.dll ReportContainer.OpenPackage)으로 패키지 열기는 된다. 즉 zip 문제가 아니라 **문서 파일(cactus/af9878b2…bin) 안의 글자 길이 칸이 어긋난 것**이다.
 · 양식 문서 안의 글자(문자열)는 [종류 1바이트 04][길이 2바이트 LE][글자] 모양(또는 [길이 2바이트][글자])이다. 날짜·측정자·회로 이름은 이 길이 칸을 새 길이로 고치고 있어 맞다(검사함: 회로 경로 16곳 길이 일치).
 · **그러나 보고서 제목을 바꾸면 길이 칸을 안 고친다.** atr_generator.js 의 `docBytes = replaceBytes(docBytes, origB, newB)` / `metaBytes = replaceBytes(metaBytes, origB, newB)` 는 글자만 바꾼다.
   - 사용자가 제목을 「EPS 1층」(8바이트)로 바꿨는데 문서 위치 55849 의 `04 18 00` (길이 24, 원래 「2026년 4분기 EPS 1층」 24바이트)가 그대로이고, 3806344 도 같고, cactus-meta 위치 236 도 같다.
   - 문서 위치 약 55512 의 파일 경로 글자 「C:\Users\user\OneDrive\Desktop\열화상플리어 보고서\2026년 4분기 EPS 1층.atr」도 앞의 길이 칸(양식에서는 88)이 그대로다(제목을 바꾸면 길이가 달라져야 함).
   → FLIR 가 길이 칸대로 읽어 뒤 자료가 어긋나 파일이 안 열린다. 제목을 안 바꾸면(기본 「2026년 4분기 EPS 1층」 그대로면) 길이가 같아서 열려 왔다.
고칠 것:
 a. 제목 바꾸기를 「글자 + 그 글자를 감싼 길이 칸」 단위로 한다. 양식에서 제목 글자(UTF-8)가 나오는 모든 자리를 찾아, 각 자리가 어떤 길이 칸에 싸여 있는지(바로 앞 2바이트가 글자 길이이거나, 더 긴 글자(경로·파일 이름)의 일부이면 그 글자 전체의 길이 칸) 판별해서 새 길이로 고친다. 지금 자리: 문서 55512 경로(전체 길이 칸), 55849 `04 18 00`, 3806344(같은 모양), cactus-meta 236(`04 18 00`). 양식에서 「2026년 4분기 EPS 1층」을 모두 찾아 빠진 자리가 없게 한다. 길이가 255 를 넘는 경우를 대비해 2바이트로 쓴다.
 b. 같은 문제가 다른 값에도 없는지 전수 점검한다: 날짜 두 가지 모양, 측정자, 회로 이름(이름·제목·경로), 쪽 줄이기(슬라이싱) 뒤 쪽 수 칸. 문서 전체에서 길이 칸으로 보이는 곳이 모두 글자 실제 길이와 맞는지 검사하는 함수를 만든다.
 c. 자동 시험(필수): 예전엔 제목을 안 바꾼 파일로만 시험해서 못 잡았다. 제목을 짧게(「EPS 1층」), 길게(40자 한글 제목), 같은 길이로 바꾼 3가지 .atr 을 만들고, 각각 (1) 위 b 의 길이 칸 검사 통과, (2) 제목 글자 앞의 `04 LL LL` 값이 새 글자 바이트 길이와 같음, (3) 경로 글자 앞 길이 칸이 새 길이와 같음을 확인하는 시험 파일(fm/thermal/ 안에 두지 말고 apps/thermal-reporter/test/ 에)을 만든다. 측정자 이름 3가지(짧게·길게·한글+영어)와 회로 이름 8개(길이 제각각)도 같이.
 d. 사람이 확인할 .atr 파일도 만든다: apps/thermal-reporter/samples/atr_test/ 에 A) 제목 그대로 B) 제목 짧게 C) 제목 길게 D) 측정자·날짜·회로 이름 모두 바꿈 — 사진은 samples\real\ 의 실제 사진 8장. 사용자가 FLIR Thermal Studio 로 열어 볼 수 있게 어느 것이 어떤 경우인지 README 에 적는다. (Claude 는 FLIR 프로그램을 직접 열 수 없다.)
 e. 같은 오류가 다른 곳(예: 파이썬 옛 판 apps/thermal-reporter/engine/atr_builder.py)에도 있으면 같이 고친다(그 폴더는 고쳐도 된다).
