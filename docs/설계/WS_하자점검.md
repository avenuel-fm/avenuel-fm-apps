#### 15.3.9 하자점검
**1. 화면 흐름** (시안: 결정 266 대화 · 휴대폰 2열 / PC 4열)
1. 점검 › 하자점검을 열면 하자 칸 1개와 오른쪽 「＋」 칸이 보입니다.
2. 하자 칸 하나 = 위에서부터 **현장명 입력 · 하자내용 입력 · 사진 자리(비어 있으면 가운데 「카메라」 버튼) · 아래 긴 「파일」 버튼**. 「사진 없음」 글자는 없음. 사진을 넣으면 그 자리에 사진이 붙고 ✕ 로 지움(다시 찍으려면 지우고 카메라).
3. 「＋」를 누르면 빈 칸이 오른쪽(줄 끝이면 다음 줄)에 늘어납니다. **새 칸 현장명 = 첫 칸 현장명 + 순서 숫자** (예: `B1 기계실` → `B1 기계실 2`, `B1 기계실 3`). 현장명은 고쳐 쓸 수 있습니다. 칸은 40개까지. 칸이 2개 이상이면 칸마다 ✕ 로 지울 수 있음.
4. 칸 아래에 **현장책임자 서명 · 시설팀 서명** 두 칸. 누르면 **손글씨 창**(소화기 점검·로그인 서명과 같은 서명 칸)이 뜨고 [확인]하면 서명이 그림으로 들어갑니다. 너무 짧게 쓰면 막고 안내.
5. 맨 아래 줄: **뒤로 · 인쇄 A4 · PDF 생성 · 저장**.
   - **저장**: 서버에 저장하고 빈 양식으로. (저장한 것은 아래 「최근 60일」 목록에서 눌러 다시 고침/삭제)
   - **PDF 생성**: **먼저 자동 저장 → PDF 를 만들어 PDF 화면으로**. 돌아오면 버튼이 **「PDF 보기」**로 바뀌고, 그때는 다시 저장·생성 없이 만든 PDF 를 그대로 엽니다. 내용을 고치면 다시 「PDF 생성」.
   - **인쇄 A4**: 저장하지 않고 지금 화면 내용을 인쇄.
6. **필수 입력**: 하자내용이 적힌 칸이 1개 이상. (현장명·사진·서명은 비워도 됨 — 서명은 종이에 직접 받을 수도 있음)

**1-1. 목록 · PDF 내려받기 (v0.26.25 월별 목록 · v0.26.28 결정 284)**
- **하자점검 메뉴를 누르면 늘 빈 양식** (전에 열었던 점검서는 남지 않음). 목록 위에 **검색창**(날짜·현장명·하자내용, 입력 0.3초 뒤 서버에서 찾음, 최대 200건).
- 아래 「저장된 하자점검서」는 **월별 아코디언**(최근 2년, 가장 최근 달만 펼침). 줄 제목 = `일자 · 첫 칸 현장명` (칸이 여러 개여도 「외 N곳」 없음), 아래 `하자 N건 · 처리 기한 · 메일 보낸 시각`.
- 저장된 점검서를 열면 「이 하자점검서 삭제」 줄 **오른쪽 끝에 「PDF 내려받기」**: 고친 것이 있으면 먼저 저장 → PDF 를 만들어 **기기(PC·휴대폰)에 파일로 저장** (`YYYY-MM-DD_하자점검.pdf`). 이미 만든 PDF 가 있으면 다시 만들지 않고 바로 내려받음.
- (v0.26.25 의 이메일 발송·서버 PDF 보관은 v0.26.28 에서 뺌 — 구글 웹앱 메일 권한 오류. 메일은 내려받은 PDF 를 직접 첨부해 보냄)

**2. 인쇄 · PDF 모양** (A4 세로, 한 쪽에 하자 8칸까지 · 8칸이 넘으면 쪽이 늘어남)
1. 제목 「하자 점검 확인서」 · 에비뉴엘 잠실점 시설팀 · **작성일 · 작성자**(로그인한 직원).
2. **사진 4열** 격자(칸마다 4:3, 자르지 않고 줄여 넣기, 아래에 현장명).
3. **하자내용 표** (번호 · 현장명 · 하자내용) — 사진과 따로 한 표로 나열.
4. 마지막 쪽 하단: 「위 하자 내용을 확인했으며 기한 내 처리하겠습니다.」 → **처리 기한 : YYYY년 M월 D일** (= 작성일 + 10일, 빈칸 없음) → **현장책임자 · 시설팀 서명 칸**(서명 그림).
5. 알려진 한계(shortcut): 하자내용이 아주 길면(칸당 300자) 한 쪽이 넘칠 수 있음 → 써 보고 칸 수 조정.

**3. 저장** (공통: `03_공통_사진과파일.md`)
- 사진·서명은 화면이 줄여(사진 1600px·70% jpg, 서명 png) 버킷 `ws-files` 의 `dw_photo/YYYY-MM/` 에 먼저 올리고, 서버 함수에는 주소·경로만 넘깁니다. 파일 표 `files` 에 이름 `YYYY-MM-DD_하자점검_###.jpg` · `…_현장책임자서명.png` · `…_시설팀서명.png`, 폴더 `점검/하자점검/YYYY/YYYY-MM`.
- ID `WS-HJ-YYYYMMDD-###` (종류 코드 `HJ`).
- **처리 기한은 서버가 `작성일 + 10일`로 계산**해 저장 (화면도 같은 식으로 보여 줌).
- 지운 것은 `deleted=true` 숨김 처리만 (파일은 그대로).
