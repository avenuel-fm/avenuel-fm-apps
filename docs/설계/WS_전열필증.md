#### 15.3.20 전열필증

**1. 화면 흐름**
```
메인 → [점검] → [전열필증]
  ① 매장명 검색 (모든 층)
  ② 층 단추 B3 · B2 · B1 · 1F~6F · 팝업   (층마다 「매장 n곳 · 기기 n」)
  ③ 매장 목록 → 누르면 펼침(휴대폰) / 오른쪽 표(PC)
       ├ 기기 줄: ☐ · 관리번호 · 기기명 · 제조사 · 승인일자 · 용량 · ✎
       ├ [＋ 이 매장에 기기 추가] → 입력 창          ← 시안 _form
       └ ⋯ 매장 메뉴: 매장 이름 바꾸기 · 매장 삭제
  ④ 고른 기기 → [필증 출력] (PC만) · [필증 삭제]   ← 아래 막대(휴대폰) / 위 단추(PC)
  [＋ 매장 추가] · [엑셀 가져오기](PC, 처음 한 번)
QR 찍기 → 필증 정보 보기 (로그인 없음)
```
- 휴대폰 = 시안 `_phone`, PC(폭 900px 이상) = 시안 `_pc`(왼쪽 층·매장 목록, 오른쪽 기기 표, 「출력함/미출력」 딱지).
- 매장 상자의 ☐를 누르면 그 매장 기기를 모두 고름.
- **출력은 PC에서만** (소화기와 같은 판단 `CAN_PRINT`). 휴대폰은 입력·편집·삭제만.
- 쓰는 사람: 로그인한 직원 모두(소화기 QR 관리와 같음). 권한을 나누려면 7장.

**2. 입력 항목**
| 칸 | 필수 | 규칙 |
|---|---|---|
| 관리번호 | 자동 | 3장. 화면에서 고칠 수 없음(회색 칸) |
| 사용장소 | 자동 | = 매장명 |
| 기기명 | ○ | 40자 |
| 용량(W) | ○ | 숫자만(1~99999). 엑셀의 `1700W`·`6W`는 숫자만 남김 |
| 제조사 | | 40자 |
| 책임자(정) | ○ | 처음 값 = 그 층 앞 기기 값(예: `1층파트리더`). 필증 「책임자」 칸에 찍힘 |
| 책임자(부) | | 처음 값 `매장관리자` |
| 승인일자 | ○ | 날짜 고르기, 저장은 `YYYY-MM-DD`, 필증은 `YYYY.MM.DD` |
- 매장: 층 + 매장명(30자). 같은 층에 같은 이름이 있으면 막음.
- 엑셀 관리대장의 「24시간 사용여부·절연저항값·허가기간·점검자」(원본 양식 시트에만 있음)는 층 시트에서 쓰지 않아 넣지 않음.

**3. 관리번호 (자동, 결정 96)**
- 모양 `{층}-{매장번호}-{순번}`. 층: `1F`~`6F`, 지하 `B1`·`B2`·`B3`(F 없음), 팝업 `팝업`. 예: `1F-1-4`, `B1-13-1`, `팝업-1-1`.
- **매장번호**: 층 안에서 매장마다 하나. 새 매장 = 그 층 가장 큰 번호 + 1.
- **순번**: 매장 안에서 가장 큰 순번 + 1. 지운 번호는 **다시 쓰지 않음**(결정 15 빈 번호 그대로).
- 엑셀에서 가져온 번호는 그대로 둠. 단 `B1F-`·`B2F-`·`B3F-`는 `B1-`·`B2-`·`B3-`로 바꿈(294대). 번호가 없거나 모양이 다르거나 겹치는 기기(실제 파일 200대)는 가져올 때 앱이 그 매장 다음 순번으로 새 번호를 매김. 매장번호 = 그 매장 기기 번호에 가장 많이 쓰인 가운데 숫자(층 안에서 겹치면 새 번호).

**4. 필증 라벨 (시안 `_label`)**
- 크기 50×50mm, 여백 1.8mm. 위 머리(9.6mm): **로고 6×6mm**(규정) + 「전열기기 신고필증」 10pt + 「롯데백화점 에비뉴엘 월드타워점」 4.8pt.
- 아래 표(굵은 테두리, 칸 폭 12.6mm · 나머지 · QR 17.4mm): 왼쪽 칸 이름 5.6pt, 값 7.6pt(관리번호 9pt).
  - 관리번호 / 사용장소 / 책임자 — 한 줄씩 가로 전체
  - 승인일자 / 용량(W) / 승인 — 오른쪽 15mm 칸에 **QR**(세 줄 높이)
  - 승인 = **「시설소장」** 고정 글자
- 값이 길면 글자를 줄여 한 줄에 맞춤(소화기 라벨과 같은 방식, 최소 4.5pt).
- QR: 오류 보정 L(칸 수가 적어 점이 굵음), 한 칸 = 프린터 4점(0.5mm), 약 16.5mm.
- 로고는 `docs/양식/전열필증_로고_CI.png`를 앱에 넣고, **인쇄 때 흑백**(프린터가 검은색만 찍음). 화면 미리보기도 흑백으로 보여 줌.
- 인쇄: 소화기와 같은 **미리보기 → [1장 시험 인쇄] / [인쇄]**, `@page` 50×50mm 여백 0, BIXOLON 설정 안내 접이. QR 칸은 프린터 점에 맞춤(결정 40). 인쇄하면 기기마다 `출력일시`를 적어 「출력함/미출력」 표시.

**5. QR**
- 내용: `{바로가기주소 또는 /exec}?eh={고유번호}`, 고유번호 12자리(소화기와 같은 글자·만드는 법, `isQrToken_`).
- 찍으면 **로그인 없이** 필증 정보 화면: 관리번호·매장·기기명·용량·제조사·책임자·승인일자. 지운 필증은 「삭제된 필증입니다. 시설팀에 알려 주세요.」
- 카메라가 필요 없어 구글 웹앱 화면에서 엶. 바로가기 페이지 `fm/ws/index.html`이 `?eh=`를 웹앱으로 넘기도록 고침(`fm/` 다시 올리기).

**6. DB 탭 (업무지원 시트, 값은 모두 글자 저장 — 결정 54)**
- `전열매장`: `es_id`(`WS-ES-YYYYMMDD-###`), `층`, `매장번호`, `매장명`, `사용여부`, `등록일시`, `등록자`, `삭제일시`
- `전열기기`: `eh_id`(`WS-EH-YYYYMMDD-###`), `es_id`, `층`, `매장명`, `관리번호`, `기기명`, `용량W`, `제조사`, `책임자정`, `책임자부`, `승인일자`, `qr_token`, `출력일시`, `사용여부`, `등록일시`, `등록자`, `수정일시`, `삭제일시`
- 삭제는 지우지 않고 `사용여부=N` + `삭제일시`(W 규칙). 매장 삭제 = 매장과 그 매장 기기 모두 N(확인 창에 기기 대수 표시).
- 매장은 이 기능만의 목록(DW 매장 `store_id`와 아직 잇지 않음). 소화기 `매장명`과도 따로.
- 기록: 추가·편집·삭제·출력·가져오기는 `기록` 탭에 한 줄(소화기와 같음).

**7. 서버 함수**
| 함수 | 권한 | 하는 일 |
|---|---|---|
| `ehList(token)` | 로그인 | 층·매장·기기 전체(사용여부 Y) + 층별 개수 |
| `ehStoreSave(token, d)` | 로그인 | 매장 추가·이름 바꾸기(매장번호 자동) |
| `ehStoreDelete(token, esId)` | 로그인 | 매장 + 그 기기 삭제 |
| `ehSave(token, d)` | 로그인 | 기기 추가(관리번호·QR 자동)·편집 |
| `ehDelete(token, ids, floor)` | 로그인 | 고른 기기 필증 삭제(여러 개). 6줄 넘으면 표를 한 번에 다시 씀 |
| `ehPrinted(token, ids, floor)` | 로그인 | 출력일시 적기 (인쇄 단추를 누를 때. 1장 시험 인쇄는 안 적음) |
| `ehImport(token, sheets, save)` | 로그인 | 엑셀 가져오기: 브라우저가 읽은 층 시트 표를 서버가 풀이(`ehParse_`, 3장 번호 규칙). save 없으면 숫자만 셈. 이미 기기·매장이 있으면 막음 |
| `ehView_(qr)` · `doGet ?eh=` | 없음 | QR 필증 정보 화면 (서버 안에서만 부름) |

**8. 엑셀 가져오기 (처음 한 번, PC)**
