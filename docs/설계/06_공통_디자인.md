## 12. 디자인 공통 (`apps/design/tokens.css`)

### 12.1 값은 한 곳에만 (결정 150)
- 원본: `apps/design/tokens.css`. 이 파일에만 색·크기 값을 적습니다.
- `python apps/design/sync.py`가 `/* DESIGN-TOKENS:START */ … END` 구간에 복사합니다. 넣는 곳: 업무지원 `Styles.html`, 도면협의 `Styles.html`, 지도 `fm/map/css/common.css`, 바로가기 `fm/index.html`·`fm/ws/index.html`·`fm/dw/index.html`·`fm/hub/index.html`, 열화상 작성기 `apps/thermal-reporter/web/tokens.css`. 확인만: `python apps/design/sync.py --check`
- 화면 코드에는 색 코드(#…, rgb)나 크기 px를 직접 적지 않습니다. 필요한 값이 없으면 새로 만들지 말고 아래 값 중에서 고릅니다.

### 12.2 색 — 6가지만
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--navy` | #1E3A5F | 주 색: 머리줄, 주요 버튼, 강조 숫자, 그래프, 본문 글자 |
| `--white` | #FFFFFF | 바탕, 카드 |
| `--text-sub` | #5F6B7A | 보조 글자 |
| `--line` | #D8DDE5 | 구역을 나누는 선, 입력칸 테두리 |
| `--tint` | #F1F4F8 | 고른 줄, 표 머리, 연한 바탕 |
| `--error` | #B42318 | **오류 문구 전용** (삭제 버튼·기한 표시 등에는 쓰지 않음) |

- 팝업 뒤를 어둡게 하는 막만 `--overlay`(남색 45%)를 씁니다.
- 사람이 직접 고르는 색(구역 표시 색 등)은 **따로 만든 색상 팔레트**에서 받고, 코드의 색으로 쓰지 않습니다.
- 예전 이름(`--ink`·`--sub`·`--muted`·`--blue`·`--green`·`--orange`·`--ground`·`--line2` …)은 위 6가지를 가리키는 **별칭**으로만 남아 있습니다. 새 코드는 6가지 이름을 씁니다.

### 12.3 글자·간격·모양
| 종류 | 값 |
|---|---|
| 글자 크기 | `--size-s` 13 · `--size-m` 15 · `--size-l` 18 · `--size-xl` 24 · `--size-xxl` 32 (px) |
| 휴대폰 입력칸 글자 | `--size-input-touch` 16px (16px보다 작으면 아이폰이 화면을 저절로 확대함) |
| 간격 (4의 배수) | `--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-6` 24 · `--sp-8` 32 · `--sp-12` 48 (px) |
| 모서리 | `--radius` 2px, **모든 모서리** (알약·원 모양 없음. 도는 표시만 예외) |
| 버튼·입력칸 높이 | `--control-h` 40px, 손가락으로 누르는 기기(`pointer:coarse`)는 `--control-h-touch` 44px |
| 그림자 | 쓰지 않음 |
| 글꼴 | `--font` Noto Sans KR. 굵기는 제목·강조 600, 나머지 500 이하 (인쇄 양식은 700) |

### 12.4 부품
- **머리줄**: 남색 바탕에 흰 글자. 머리줄 안의 주요 버튼은 흰 바탕·남색 글자.
- **버튼**: 화면에서 가장 중요한 버튼 하나만 남색 채움(`.btn.pri`). 나머지는 흰 바탕(`.btn`). 위험한 일(`.btn.warn`)도 흰 바탕에 남색 테두리.
- **서류 화면 아래 버튼 줄** (결정 176): 왼쪽에 상태 글자(저장 안 함·저장됨), 오른쪽 아래에 **[인쇄 (B4)] [저장 ⇄ PDF 보기]**. 남색은 「저장」 하나. 저장하면 PDF도 같이 만들고, 끝나면 그 자리가 흰 「PDF 보기」, 고치면 다시 「저장」. 인쇄는 PC만. 코드는 `docBar`·`docSlot`(Index.html) 하나를 모든 서류 화면이 같이 씀. 시안: `docs/시안/WS-버튼통일/`.
- **표 머리**: `--tint` 바탕.
- **상태 표시** (색이 아니라 모양과 글자로):
  - 문제·불량·미흡: 남색 **채움** (`.c-bad`, `.c-miss`, `.chip.orange`)
  - 정상·완료: 흰 바탕 **남색 테두리** (`.c-ok`, `.chip.green`)
  - 대기·미점검: 흰 바탕 **회색 테두리**, 보조 글자 (`.c-wait`)
- **그래프**: 남색 한 가지, 눈금선은 `--line`.
- 누름·올림 (결정 82): 마우스 올림 색은 `@media (hover:hover)` 안에만, 버튼은 누르는 동안 `scale:.96`(0.15초, `prefers-reduced-motion:no-preference`일 때만, 꺼진 버튼 제외), 누를 때 회색 번쩍임 끔(`-webkit-tap-highlight-color:transparent`), 스크롤되는 팝업·목록은 `overscroll-behavior:contain`

### 12.5 규칙에서 빼는 것
- 인쇄·PDF·라벨 양식 (TBM, 종합업무일지, 공조기, 공사장 점검 PDF, 필증 라벨, 도면 검토서, 동의서): 원래 색·크기 그대로. `tokens.css` 끝의 「양식」 구간이 예전 색을 고정합니다.
- 서명 글씨, 카메라 화면, 지도 도면 그림, 도면협의 달력 구분 색, 열화상 그래프의 상(R·S·T) 구분 색.

**어두운 화면 (결정 98, WS v0.9.2 · DW v1.8.11)**
- **「어둡게 / 밝게」** 버튼: 업무지원은 **메인 메뉴 맨 아래 왼쪽**(v0.9.3), 도면협의는 대시보드 위 막대. 처음엔 휴대폰 설정(라이트·다크)을 따르고, 고르면 그 기기에 기억(`fm_theme`).
- 방법: 색 변수를 따로 만들지 않고 화면 전체를 뒤집음(`filter: invert(1) hue-rotate(180deg) contrast(.78)` — 검정이 아니라 **진한 회색** 바탕, v0.9.3, `Styles.html` 끝). 사진·서명·QR·카메라(`img·video·canvas·.keep-color`)는 원래 색. **인쇄·그림 저장·PDF는 늘 흰 바탕** (`@media screen`만, html2canvas는 filter를 안 읽음).
- QR 점검 화면(`fm/ws/check.html`)은 버튼 없이 휴대폰 설정만 따름(다른 주소라 기억을 못 넘겨받음).
- shortcut: 남색·빨강이 원래보다 조금 밝게 보임. 색을 하나하나 맞추려면 색 변수 방식으로 바꿈.

**뒤로 버튼 · 알림 (결정 102, WS v0.9.2)**
- 위 막대 왼쪽 `<` 버튼은 없앰. 메인이 아닌 화면은 **맨 아래에 큰 「‹ 뒤로」 버튼** (아래 고정 막대가 있는 화면은 그 위로 띄움).
- 알림(토스트)은 **줄을 세워 하나씩**: 보이는 시간(환경설정, 기본 2.6초) → 0.5초 쉬고 다음. 같은 글이 바로 이어 오면 한 번만.

**화면 다듬기 (결정 110, WS-25, unslop 점검)**
- 그림 문자(📷 📂 📄 🔥 ✉ ⚠ 등)는 쓰지 않고 **선 아이콘** 하나의 모양으로 (굵기 1.75, 글자 크기에 맞춤, 글자색 따라감). 체크 ✓ · 닫기 ✕ 글자는 그대로.
- 글자 굵기: 화면 제목·강조 **600**, 나머지 **500** 이하. **인쇄·PDF·라벨 양식은 700 그대로.**
- 단어 중간 줄바꿈 막기 (`word-break:keep-all`). 인쇄 쪽은 원래 줄바꿈 그대로.
- 업무지원: 아래 저장 줄이 있는 화면은 **그 줄 맨 왼쪽에 「‹ 뒤로」**(결정 102의 큰 뒤로 줄 대신). 저장 줄이 없는 화면은 맨 아래 큰 「뒤로」 그대로.
- 메뉴 순서·어두운 화면은 그대로. (색·크기는 12.1~12.3, 결정 150)
