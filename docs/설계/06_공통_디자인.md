## 12. 디자인 공통 (`common.css`)
- **기준은 도면협의 v1.8 `Styles.html`입니다.**
- 색상 변수 이름도 DW 이름을 기준으로 합니다.
  - WS v0.3이 정한 이름은 **별칭**으로 함께 정의합니다.
  - 두 이름 체계는 같은 이름 `--line`이 **서로 다른 색**을 뜻하기 때문에, 섞어 쓰면 테두리 색이 틀어집니다.

| 기준 이름 (DW) | 값 | WS 별칭 | 용도 |
|---|---|---|---|
| `--ground` | #F4F6F8 | `--bg` | 배경 |
| `--card` | #FFFFFF | `--surface` | 카드 |
| `--line2` | #DCE1E7 | (WS `--line`) | 카드 테두리 |
| `--line3` | #EDF0F3 | `--line-soft` | 표 구분 |
| `--line` | #CBD2DB | `--input-line` | 입력칸·버튼 테두리 |
| `--ink` / `--sub` / `--muted` | #18202B / #3F4855 / #5B6573 | `--text` / `--text-2` / `--muted` | 글자 |
| `--blue` / `--blue-d` / `--blue-bg` | #1F5FA8 / #174A84 / #E8F0FA | `--primary` / `--primary-dark` / `--primary-soft` | 주 색 |
| `--green` / `--green-bg` | #1F7A4D / #EAF5EF | `--ok` / `--ok-soft` | 완료 |
| `--orange` / `--orange-bg` | #B4410F / #FDF0E8 | `--warn` / `--warn-soft` | 주의 |
| `--red` | #C0261A | — | 오류·기한 지남 |

- WS의 `--line`은 DW `--line`과 색이 다릅니다. **새 코드에서는 `--line` 대신 기준 이름(`--line2`)을 씁니다.**
- `--warn-soft`는 WS 값(#FFF7F2) 대신 DW 값(#FDF0E8)으로 통일합니다.

**부품과 크기**
- 부품: `.btn`(`.pri`, `.green`, `.warn`, `.sm`), `.inp`, `.seg`, `.chip`, `.kpi`, `.todo`, `.dialog`, 토스트, PIN 팝업
- 글꼴: Noto Sans KR 400/500/700. 입력칸은 16px 이상입니다.
- 모서리: 입력·버튼 8px, 카드 12px, 칩 999px
- 높이: 버튼·입력 44px, 휴대폰 주 버튼 52px
- 누름·올림 (결정 82): 마우스 올림 색은 `@media (hover:hover)` 안에만, 버튼은 누르는 동안 `scale:.96`(0.15초, `prefers-reduced-motion:no-preference`일 때만, 꺼진 버튼 제외), 누를 때 회색 번쩍임 끔(`-webkit-tap-highlight-color:transparent`), 스크롤되는 팝업·목록은 `overscroll-behavior:contain`
