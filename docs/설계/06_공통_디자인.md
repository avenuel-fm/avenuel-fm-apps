## 12. 디자인 공통 (`common.css`)
- **기준은 도면협의 v1.8 `Styles.html`입니다.**
- 색상 변수 이름도 DW 이름을 기준으로 합니다.
  - WS v0.3이 정한 이름은 **별칭**으로 함께 정의합니다.
  - 두 이름 체계는 같은 이름 `--line`이 **서로 다른 색**을 뜻하기 때문에, 섞어 쓰면 테두리 색이 틀어집니다.

| 기준 이름 (DW) | 값 | WS 별칭 | 용도 |
|---|---|---|---|
| `--ground` | #F4F6F8 | `--bg` | 배경 |
| `--card` | #FFFFFF | `--surface` | 카드 |
| `--line2` | #DCE1E7 | (WS `--line`) | 카드 테두리 |
| `--line3` | #EDF0F3 | `--line-soft` | 표 구분 |
| `--line` | #CBD2DB | `--input-line` | 입력칸·버튼 테두리 |
| `--ink` / `--sub` / `--muted` | #18202B / #3F4855 / #5B6573 | `--text` / `--text-2` / `--muted` | 글자 |
| `--blue` / `--blue-d` / `--blue-bg` | #1F5FA8 / #174A84 / #E8F0FA | `--primary` / `--primary-dark` / `--primary-soft` | 주 색 |
| `--green` / `--green-bg` | #1F7A4D / #EAF5EF | `--ok` / `--ok-soft` | 완료 |
| `--orange` / `--orange-bg` | #B4410F / #FDF0E8 | `--warn` / `--warn-soft` | 주의 |
| `--red` | #C0261A | — | 오류·기한 지남 |

- WS의 `--line`은 DW `--line`과 색이 다릅니다. **새 코드에서는 `--line` 대신 기준 이름(`--line2`)을 씁니다.**
- `--warn-soft`는 WS 값(#FFF7F2) 대신 DW 값(#FDF0E8)으로 통일합니다.

**부품과 크기**
- 부품: `.btn`(`.pri`, `.green`, `.warn`, `.sm`), `.inp`, `.seg`, `.chip`, `.kpi`, `.todo`, `.dialog`, 토스트, PIN 팝업
- 글꼴: Noto Sans KR 400/500/700. 입력칸은 16px 이상입니다.
- 모서리: 입력·버튼 8px, 카드 12px, 칩 999px
- 높이: 버튼·입력 44px, 휴대폰 주 버튼 52px
- 누름·올림 (결정 82): 마우스 올림 색은 `@media (hover:hover)` 안에만, 버튼은 누르는 동안 `scale:.96`(0.15초, `prefers-reduced-motion:no-preference`일 때만, 꺼진 버튼 제외), 누를 때 회색 번쩍임 끔(`-webkit-tap-highlight-color:transparent`), 스크롤되는 팝업·목록은 `overscroll-behavior:contain`

**어두운 화면 (결정 98, WS v0.9.2 · DW v1.8.11)**
- **「어둡게 / 밝게」** 버튼: 업무지원은 **메인 메뉴 맨 아래 왼쪽**(v0.9.3), 도면협의는 대시보드 위 막대. 처음엔 휴대폰 설정(라이트·다크)을 따르고, 고르면 그 기기에 기억(`fm_theme`).
- 방법: 색 변수를 따로 만들지 않고 화면 전체를 뒤집음(`filter: invert(1) hue-rotate(180deg) contrast(.78)` — 검정이 아니라 **진한 회색** 바탕, v0.9.3, `Styles.html` 끝). 사진·서명·QR·카메라(`img·video·canvas·.keep-color`)는 원래 색. **인쇄·그림 저장·PDF는 늘 흰 바탕** (`@media screen`만, html2canvas는 filter를 안 읽음).
- QR 점검 화면(`fm/ws/check.html`)은 버튼 없이 휴대폰 설정만 따름(다른 주소라 기억을 못 넘겨받음).
- shortcut: 파랑·빨강이 원래보다 조금 밝게 보임. 색을 하나하나 맞추려면 색 변수 방식으로 바꿈.

**뒤로 버튼 · 알림 (결정 102, WS v0.9.2)**
- 위 막대 왼쪽 `<` 버튼은 없앰. 메인이 아닌 화면은 **맨 아래에 큰 「‹ 뒤로」 버튼** (아래 고정 막대가 있는 화면은 그 위로 띄움).
- 알림(토스트)은 **줄을 세워 하나씩**: 보이는 시간(환경설정, 기본 2.6초) → 0.5초 쉬고 다음. 같은 글이 바로 이어 오면 한 번만.

**화면 다듬기 (결정 110, WS-25, unslop 점검)**
- 그림 문자(📷 📂 📄 🔥 ✉ ⚠ 등)는 쓰지 않고 **선 아이콘** 하나의 모양으로 (굵기 1.75, 글자 크기에 맞춤, 글자색 따라감). 체크 ✓ · 닫기 ✕ 글자는 그대로.
- 글자 굵기: 화면 제목·강조 **600**, 나머지 **500** 이하. **인쇄·PDF·라벨 양식은 700 그대로.**
- 단어 중간 줄바꿈 막기 (`word-break:keep-all`). 인쇄 쪽은 원래 줄바꿈 그대로.
- 업무지원: 아래 저장 줄이 있는 화면은 **그 줄 맨 왼쪽에 「‹ 뒤로」**(결정 102의 큰 뒤로 줄 대신). 저장 줄이 없는 화면은 맨 아래 큰 「뒤로」 그대로.
- 색·글꼴·메뉴 순서·어두운 화면은 그대로.
