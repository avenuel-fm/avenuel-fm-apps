#### 15.3.18 서류작업

**1. 메뉴**
```
메인 2×3 첫 칸 [서류작업] (예전 [TBM])
  ├─ TBM               ← 이 문서 2~6장
  ├─ 명일 작업 예정     ← 양식 받은 뒤 이 문서에 장 추가
  └─ (그 밖의 서류)     ← 추가될 때마다 이 문서에 장 추가
```
- 메인 배치: `[서류작업] [작업] / [점검] [일정] / [하자점검] [결재 대기·내 문서]` (15.3.4)

**2. 로그인 서명 — 매일 첫 로그인 (결정 56)**
1. PIN 4자리 → 맞고 오늘 서명이 없으면 **서명 칸**(가로로 넓은 칸, 휴대폰 가로 폭 가득). 칸 가운데에 **본인 이름을 연회색 굵은 글자**로 깔고 그 위에 따라 씀 (소화기 손글씨 칸과 같은 모양, 결정 46).
2. [지우기]로 다시 쓰기. **너무 짧게 그은 서명은 받지 않음**(소화기 칸과 같은 기준) (개선 A).
3. [서명하고 로그인] → 서명 그림을 **가로 600px 흑백 PNG**(흰 바탕·검은 글씨만, 보통 10KB 안팎)로 줄여 드라이브에 저장하고 WS `서명` 탭에는 **파일 번호만** 한 줄. 그 뒤 기기 표 발급(02 7.2). 로그인이 느려지지 않게 하려는 것 (결정 60).
   - **서명하지 않으면 로그인되지 않습니다.** 건너뛰기 버튼 없음. [PIN 다시]로 처음 화면만 돌아감 (결정 60).
4. **그날 이미 서명했으면 다시 묻지 않음**: 같은 근무일에 다른 기기·새로고침·입장표(`?t=`)로 들어와도 PIN만(또는 입장표만)으로 들어감 (개선 B).
5. **근무일**: **오전 6시 시작**. 오전 6시~다음 날 오전 5시 59분 = 같은 근무일(출근은 8시까지지만 일찍 오는 직원 고려). 기기 표 만료도 다음 오전 6시라 경계가 같음 (결정 60). 예: 11월 5일 06:10 로그인 → 11월 5일 근무일, 11월 5일 05:30 로그인 → 11월 4일 근무일.
6. 혹시 기기 표는 살아 있는데 오늘 서명 줄이 없으면(시트에서 지운 경우 등) 메인 대신 서명 칸이 뜸 (`signToday`).
- 서명은 **TBM 서명용**입니다. 결재 직인(`직원.직인이미지ID`, 11.3)과는 따로입니다.

**3. 서명 저장**
| 항목 | 규칙 |
|---|---|
| 드라이브 | `시설팀 통합업무/20_업무지원/서류작업/서명/{YYYY-MM}/{YYYY-MM-DD}_서명-{이름}.png` (날짜 = 근무일) |
| WS `서명` 탭 | sign_id(`WS-SG-YYYYMMDD-###`), 근무일, staff_id, 이름, 파트명, 서명_id(파일), 서명시각, 들어온길(PIN/입장표), TBM사용(Y/N), 삭제여부 |
| 하루 한 번 | 같은 근무일·같은 직원 줄이 있으면 새로 받지 않음 |
| 보관 (개선 C) | **TBM PDF에 쓰인 서명은 계속 보관**. 쓰이지 않은 서명은 **90일 뒤 휴지통**(매일 새벽 예약 작업, `삭제여부=Y`) |
| 종류 코드 | `SG` 서명 (01 4장 등록부) |

**4. TBM 서명란 — 로그인한 순서대로 (결정 56)**
- 서명란은 **미리 채우지 않습니다.** 그날 `서명` 탭에 쌓인 줄을 **서명시각 순서대로** 읽어 1번 칸부터 채웁니다.
- **그날 로그인한 직원만** 들어갑니다. **파트 구분 없이 전 직원 섞어서** 순서대로입니다.
- TBM 화면을 연 뒤에 로그인한 사람도, TBM을 다시 열거나 [새로고침]하면 다음 칸에 들어갑니다. 늦게 받아도 저장만 되어 있으면 됩니다.
- 서명란 칸 수보다 많으면 다음 쪽에 이어서 (양식 받은 뒤 확정).
- 각 서명 아래에 **로그인(서명) 시각**을 작게 표시 — 화면과 PDF 모두 (예: `07:42`) (결정 60).
- v0.4.0 화면: [서류작업 → TBM]에 오늘 근무일 서명 목록(순번·이름·파트·시각·서명 그림)과 [새로고침]. 사진·PDF는 양식 받은 뒤.

**5. TBM 작성 · PDF (결정 58)**
1. [서류작업 → TBM] → 오늘(근무일) TBM. 위에 서명란 미리보기(로그인 순서), 아래 사진 칸 2개: **회의 사진 · 구호 사진** (가로 4:3, 9.3). 사진은 휴대폰 기본 카메라(9.3 결정 44).
2. [사진 저장] → 사진 2장만 저장(TBM 탭 한 줄). **이때 PDF는 만들지 않습니다** (결정 58, 11-05 수정).
3. 서명이 늦게 들어와도 됩니다. 화면의 서명 목록에서 다 들어왔는지 확인합니다.
4. **[PDF로 저장]** (따로 있는 버튼) → 양식(Slides 템플릿, 11.1)에 날짜·작성자·사진 2장·그 시각까지의 서명(로그인 순, 서명 아래 시각)을 채워 PDF로 저장. 이때 쓰인 서명은 `TBM사용=Y`. 출력은 이 PDF로.
5. 저장: `시설팀 통합업무/20_업무지원/서류작업/TBM/{YYYY}/{YYYY-MM}/{YYYY-MM-DD}_TBM.pdf`. 문서색인 1줄(`WS-TB-…`, 4장).
6. **PDF로 저장한 뒤 서명이 더 들어오면** 「PDF 뒤 서명 n명 추가」 표시 → [PDF로 저장]을 다시 누르면 같은 이름으로 새로 만들고 예전 PDF는 휴지통.

**6. DB 탭 (`20_업무지원_DB`)**
| 탭 | 열 |
|---|---|
| 서명 | sign_id, 근무일, staff_id, 이름, 파트명, 서명_id, 서명시각, 들어온길, TBM사용, 삭제여부 |
| TBM | tbm_id(`WS-TB-YYYYMMDD-###`), 근무일, 작성자_id, 작성자명, 회의사진_id, 구호사진_id, 서명수, pdf_id, PDF상태, PDF시도횟수, PDF만든시각, 작성시각, 수정시각, 삭제여부 |

**7. 서버 함수 (예정)**
| 함수 | 권한 | 하는 일 |
|---|---|---|
| `login(pin, deviceId, signPng)` ✅ | — | PIN 확인(5회 잠금 공통). 오늘 서명이 없고 `signPng`도 없으면 `{needSign, name}`만 돌려줌(표 안 줌) → 서명과 함께 다시 부르면 서명 저장 → 기기 표 |
| `bootstrap(token)` ✅ | 로그인 | `needSign`(오늘 서명 없음), `docs.signs`(오늘 서명 수) 같이 줌 |
| `signToday(token, signPng)` ✅ | 로그인 | 표는 있는데 오늘 서명이 없을 때 (입장표 포함) |
| `tbmToday(token)` ✅ | 로그인 | 오늘 근무일 서명 목록(로그인 순, 이름·파트·시각·그림) |
| `tbmSubmit(token, d)` / `buildTbmPdf(token, id)` | 작성 권한 | 사진 저장 / [PDF로 저장] — 양식 받은 뒤 |
| `cleanSigns_()` ✅ | 예약 작업(매일 새벽 3시) | 90일 지난 안 쓴 서명 휴지통. 시트 메뉴 ⑥에서 예약 켬 |
