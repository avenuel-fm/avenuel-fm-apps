[증상 — 사용자 확인 11-21]
「내려받기」로 받은 .atr 를 FLIR Thermal Studio 로 열면 쪽에서 **오른쪽 열화상 사진 자리에 열화상 그림이 없고**, 스팟 표시 그림(좌측 위 작은 검은 박스 「스팟 1 : 28.1 °C …」와 작은 원 3개 1·2·3)만 떠 있다(스크린샷 1: 1층 1번 일반 쪽). 왼쪽 실화상 자리에는 사진이 있다. 그런데 사용자가 **FLIR 에서 스팟을 조금 조정하고 저장하면** 사진이 정상(열화상 + 눈금 32.1/28.1 °C + Sp1·Sp2·Sp3 표시, 스크린샷 2)으로 나온다.
→ FLIR 가 스팟을 조정·저장할 때 **자기가 쪽 그림 사본을 다시 만들어 넣는다.** 그 결과가 FLIR 가 기대하는 정확한 형식이다. 우리가 만든 사본이 그 형식과 어디가 다른지 비교해서 같게 만들면 된다.

[할 일]
1. **사용자가 두 파일을 준다**(Claude/사용자가 해 둘 것): 같은 보고서에서 ① 작성기 「내려받기」로 받은 원래 .atr (스팟을 안 건드린 것) ② 그것을 FLIR 에서 열어 스팟을 조정하고 **저장한 .atr**. 위치: apps/thermal-reporter/samples/atr_flir_saved/ (before.atr, after.atr). 파일이 아직 없으면 사용자에게 달라고 한다. 둘 다 같은 사진 1~2장짜리면 충분하다(작을수록 좋다).
2. **before / after 문서 비교(핵심)**: 두 파일의 문서 파일(cactus/af9878b2aa8e47faaf8942d892cde994.bin)에서 쪽마다 들어 있는 그림 사본들을 서명(JPEG FF D8 FF, PNG 89 50 4E 47)으로 전부 찾아 표로 만든다: 위치, 형식, 해상도, 바이트 길이, 앞 4바이트 길이 칸 값, PNG 이면 색 방식(RGBA/RGB/팔레트)·투명 여부·비트 깊이, JPEG 이면 크기·압축 방식(baseline/progressive)·FLIR 자료(APP1) 포함 여부. before 와 after 에서 **무엇이 바뀌었는지**(어느 그림이 달라졌고, 새 그림이 어떤 모양인지)를 정리한다.
   - 가설 A: 열화상 본체 JPEG(320×240, 양식에서는 38KB)를 우리는 **사진 원본 파일 전체**(FLIR 자료가 든 400KB 안팎)로 넣는다. FLIR 가 만드는 것은 그림만 든 작은 JPEG 일 수 있다 → 그림만 다시 인코딩한 작은 JPEG 로 바꾼다(팔레트 색을 입힌 열화상, 눈금·글자 없는 그림).
   - 가설 B: 오른쪽 그림은 「열화상 본체 JPEG + 스팟 표시 PNG(690×517, 투명 바탕)」 두 장을 겹쳐 그린다. 우리 PNG 가 불투명이거나, 크기·위치가 어긋나거나, 본체 JPEG 가 한 장이 아니라 두 장(24KB 짜리 포함)인지 확인.
   - 가설 C: 그림 앞 4바이트 길이 칸 말고 **그림 사이의 다른 칸**(해상도·형식 코드·시각·해시)이 있어 FLIR 가 사본이 무효라고 보고 버린다. before/after 의 사본 앞뒤 바이트(앞 64바이트·뒤 64바이트)를 나란히 비교한다.
3. 비교 결과대로 `atr_generator.js` 의 `transformPage`(쪽 사본 4장 만들기)를 FLIR 가 만드는 사본과 **같은 형식·같은 해상도·같은 인코딩**으로 고친다. 열화상 그림은 사진 파일 안 열화상 자료(원시 온도 + 팔레트)로 직접 그려도 되고(flir_parser.js 가 이미 온도를 계산함), 파일 안 카메라 JPEG(우리 원본)를 그림 부분만 다시 인코딩해도 된다. 스팟 표시 PNG 도 after 의 것과 같은 모양(눈금·스팟·글자 위치와 크기, 글꼴 느낌)으로.
4. 같은 비교로 **쪽 목록 미리보기**(문서 앞부분의 170×240 JPEG 5장, 양식의 옛 쪽 그림)도 after 에서 어떻게 바뀌는지 확인하고, 가능하면 새 쪽 그림으로 만든다(안 되면 못 했다고 적는다).
5. after 에서 **글자 칸·그림 외 바뀐 곳**(예: 시각, 번호, 크기 칸)이 있으면 모두 정리해서 알려 준다. 쪽 수 1·3·8 모두에서.
6. 시험용 .atr 을 samples/atr_test3/ 에 만들고(사진 samples\real 에서 3장), README 에 FLIR 에서 확인할 것(스팟 안 만져도 열화상이 보이는가, 눈금 값이 맞는가)을 적는다. 사용자가 열어 확인한다. Claude 는 FLIR 를 직접 열 수 없다.
