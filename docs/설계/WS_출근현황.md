#### 15.3.19 출근현황

**1. 화면 흐름**
```
[서류작업] → [출근현황]
  ① 날짜 고르기 (달력, 처음엔 오늘 근무일)          ← 시안 _1날짜
  ② 그날 조직도 + 합계 표                             ← 시안 _2휴대폰 · _3PC
       ├ 상태 딱지(▾) 누르기 → 상태 고르기 (그날만)    ← 시안 _6상태고르기
       └ 이름 누르기 → 기본 휴일 보기·고치기          ← 시안 _7기본휴일
  ③ [그림 저장] → 휴대폰에 PNG 내려받기               ← 시안 _4그림
  [엑셀 올리기] → .xlsx 고르기 → 확인 → [저장]        ← 시안 _5엑셀올리기
```
- 근무일은 **오전 6시 시작** (결정 60). 새벽에 열면 전날 근무일이 먼저 보임.
- 달력 칸에는 그날 주간 인원(「주 n」)을 작게 보여 줌. 엑셀을 올린 달만 고를 수 있음.
- 엑셀 「점휴」(백화점 휴일) 표시는 **무시**함 (11-07 사용자).

**2. 상태 기호 (엑셀 → 앱)**
| 엑셀 | 뜻 | 앱 딱지 | 앱 색(엑셀 색을 부드럽게) | 합계 칸 |
|---|---|---|---|---|
| (빈 칸) | **출근** (11-07 사용자) | 출근 | 연초록 | 주 |
| `9-7` | 9시 출근·7시 퇴근 | 9-7 | 흰 바탕·회색 테두리 | 주 |
| `휴` | 휴일 | 휴 | 연노랑 | 휴무 |
| `연` | 연차 | 연 | 연빨강 | 휴무 |
| `법` | 법휴 | 법 | 연분홍 | 휴무 |
| `병가` | 병가 (11월 파일에서 처음 봄) | 병가 | 연보라 | 휴무 |
| `야` | 야간 | 야 | 연파랑 | 야 |
| `비` | 비번 | 비 | 연회색 | 비번 |
| `A반`·`전반` / `P반`·`후반` | 오전 / 오후 반차 | A반 / P반 | 연빨강 테두리 | **주** (11-07 사용자) |
| `A검진` / `P검진` | 오전 / 오후 검진 (11-07 확인) | A검진 / P검진 | 연청록 | **주** (11-07 사용자) |

- 엑셀 수식에는 `대`(대휴)·`경`·`.`도 휴무로 나옴 → 들어오면 휴무로 셈.
- **모르는 기호**가 있으면 올릴 때 주황 글씨로 알려 주고(몇 칸·누구), 저장은 됨. 그 칸은 글자 그대로 회색 딱지.
- 「휴무」에는 연·병가도 들어감 (게시판 휴무 칸과 같음).

**3. 누가 무엇을 하나 (11-07 사용자)**
| 일 | 할 수 있는 사람 |
|---|---|
| 보기 · 그림 저장 | 로그인한 전 직원 |
| **그날 상태 고치기** (딱지 누르기) | 소장 · 부소장 · 총무 · **그날 또는 전날 야간(`야`) 근무자** (야간은 아침 8시 30분에 끝나 다음 날 아침 게시판도 그 사람이 맞춤) |
| **엑셀 올리기** | 소장 · 부소장 · 총무 |
| **기본 휴일 고치기** | 소장 · 부소장 · 총무 (다른 사람은 이름을 누르면 보기만) |
| **파트 바꾸기 · 직원 삭제** (결정 306) | 소장 · 부소장 · 총무 + **그 달 엑셀 관리파트(구역 「관…」) 인원** |
- 사람 구분: 로그인한 직원의 **WS `직원` 탭 역할**(소장·부소장) 또는 **그 달 엑셀 직책**(소장·부소장·총무, 이름으로 찾음). 관리자 역할은 넣지 않음 (결정 90). [엑셀 올리기] 버튼도 이 세 사람에게만 보임. 그 달 엑셀을 처음 올릴 때는 올리는 엑셀의 직책으로 봄. 야간 근무자는 그날 스케줄(고친 값 포함)에서 `야`인 사람을 **이름으로** 찾음 (직원 탭 이름 = 엑셀 이름이어야 함).
- 권한이 없는 사람에게는 딱지에 ▾ 표시가 없고 눌러도 아무 일 없음. 서버도 다시 확인함.

**4. 엑셀 올리기 (결정 88: A안 엑셀 파일)**
- 읽는 방법: 화면에서 엑셀 읽기 도구(SheetJS)로 읽어 서버에 칸 글자만 보냄. 칸에 글자(휴·야·9-7…)가 있어 색은 안 씀.
- 11월 파일 모양 (`11월` 시트 하나): 1줄 제목 `(2026년 11월) 근무스케줄` → **달은 제목에서 읽음**. 5줄 날짜(1~30), 6줄 요일. A열 구역(합친 칸), B열 직책, C열 이름, E열부터 1일.
- 읽는 규칙: B열에 「합계」가 든 줄은 건너뜀. 날짜 줄에서 1~31이 있는 열만 읽음(대휴·입사일·연차 칸은 안 읽음). **이름이 빈 줄 = 공석**. 단 **엑셀에서 숨긴 빈 줄은 읽지 않음** (11월 28줄·12월 27줄 기계·건축 기사, 엑셀 화면엔 안 보임). 숨긴 줄이라도 이름이 있으면 읽음 (11월 총무 줄 숨김 → 권한 유지) (결정 106). 직책 칸이 비어도 이름이 있으면 읽음 (「공사장 안전관리」는 구역·직책 칸이 합쳐져 있음).
- 확인: 앱이 센 날짜별 주간 인원을 엑셀 「주간근무총원」 줄과 맞춰 보고, 다르면 알려 줌. **11월 파일 30일 모두 같음** (11-07). 엑셀 총원은 **공사장 안전관리를 빼고** 세므로 앱도 빼고 맞춰 봄, 총원 칸이 빈 날은 안 맞춰 봄 (결정 106). 11-13 새 파일은 3~5일 「공가」, 9일 「입사」를 엑셀이 주간 인원에 넣어 다르게 나옴 (앱은 처음 보는 기호 → 휴무).
- 같은 달을 다시 올리면 그 달 줄을 새 것으로 바꿈(예전 줄 `삭제여부=Y`). **그날 고친 값과 기본 휴일은 그대로 둠.**
- 엑셀 모양이 바뀌어 못 읽으면: 엑셀에서 표를 복사해 붙여넣기 칸(같은 규칙) → 그래도 안 되면 딱지 고치기.
- 원본 파일은 드라이브 `시설팀 통합업무/20_업무지원/서류작업/출근현황/{YYYY-MM}_근무스케줄.xlsx`에 보관 (GitHub에는 안 올림).
- 비교했던 다른 안: B 스크린샷 + AI 판독(AI-1 보류 중이라 뺌), C 앱에서 한 달 직접 입력, D 붙여넣기(→ 위 대안으로 남김).
- **엑셀 AS열**에 「금토」「일월」 같은 요일이 적혀 있으나 실제 휴 칸과 맞지 않아 **읽지 않음**. 기본 휴일은 앱에서 정함(6장).

**5. 조직도 화면 · 그림 (시안 `_2`·`_3`·`_4`)**
- 구역: **사업소장**(소장 줄) / **관리파트**(관리 구역 나머지: 부소장·총무) / **전기·방재** / **기계·건축** / **공사장 안전관리**(결정 106, 엑셀에선 가운데지만 **맨 아래**, 주황). 순서·직책은 **엑셀 그대로**, 이름도 엑셀 이름 그대로 (WS `직원` 탭과 따로 맞추지 않음, 11-07 사용자).
- 사람 칸: 직책 · 이름 · 상태 딱지. 공석은 점선 칸 「공석」, **구역 맨 끝**에 둠 (결정 90).
- 이름은 줄이지 않고 다 보임: 칸 폭을 화면에 맞춰 자동(한 칸 최소 170px, 휴대폰은 2칸·이름 14px). 출근 딱지는 **「출」 한 글자**, 직책 `교대반장`은 **「교대」**로 보임 (교대반장이라는 직급은 없음, 결정 90). 상태 딱지 안내 문장은 15px로 키우고, 「고칠 수 있는 사람」 문장은 뺌.
- 합계 표 (게시판과 같은 모양): **파트별 인원현황**(전체 = 엑셀 줄 수, 현재 = 이름 있는 줄, 공석) / **금일 근무인원**(주·야) / **금일 휴무인원**(휴무·비번).
- **화면 다듬기 (결정 108, unslop)**: 색은 **상태 칸에만**(엑셀 근무표 색). 구역 머리·표 머리는 회색 하나(전: 구역마다 다른 색). 상태 칸은 모서리 6px 네모(엑셀 칸 모양), 누를 수 있는 칸은 아래 그림자(▾ 없음). 안내 「상태 칸을 눌러 이날 상태를 고릅니다 · 이름을 누르면 기본 휴일을 봅니다」는 상자 없이 15px. 날짜·저장·엑셀 올리기 화면의 그림 문자는 선 아이콘. 굵기 600.
- 그날 고친 칸은 딱지 옆에 작은 점 「고침」(누가·언제는 눌러서 봄).
- 그림 잘림 고침 (v0.7.1): 그림 도구의 종이 크기를 그림 판 크기로 정함 (안 정하면 A4 폭에 맞춰 밀려 잘림, TBM PDF와 같은 방식).
- 그림: **가로 1200px 판**(11-07 사용자)을 또렷하게 2배로 그려 파일은 가로 2400px, 파일 이름 `YYYY-MM-DD_출근현황.png`, 휴대폰에 내려받기만(드라이브 저장 안 함, 결정 68과 같음). 맨 위 `2026년 11월 7일 (토) 근무인원` · 부제 「잠실점 에비뉴엘 시설관리」, 맨 아래 `업무지원 앱 · 만든 시각` (「만듦」 글자 없음). 표 제목은 가운데. 그림 도구가 글자를 약 3px 아래로 그려, **그림 만들 때만** 딱지 글자를 3px 올림 (결정 106). 그림에는 ▾·밑줄 같은 고치기 표시를 넣지 않음.

**6. 그날 상태 고치기 · 기본 휴일**
- **그날 고치기** (시안 `_6`): 딱지 누름 → 12가지(출근·9-7·휴·연·법·야·비·병가·A반·P반·A검진·P검진) 중 고름 → 그날만 바뀜. [엑셀 값으로 되돌리기]. 고친 사람·시각 기록.
- **기본 휴일** (시안 `_7`): 이름 누름 → 요일 7칸(여러 개 고름). 예: 소장 = 일·월.
  - 적용 규칙: 그 요일에 **엑셀이 빈 칸(출근)이면 「휴」로 봄**. 엑셀에 다른 값(연·9-7·야 등)이 있으면 엑셀 값이 먼저. 그날 고친 값이 가장 먼저.
  - 순서: **그날 고친 값 > 엑셀 값(빈 칸 아님) > 기본 휴일 > 출근**.
  - 기본 휴일은 **달이 바뀌어도 계속** 씀(이름으로 저장).
- **파트 (결정 306)**: 이름 메뉴 아래 체크 칸 [전방파트 (전기·방재)] [기건파트 (기계·건축)] — 하나만. 로그인 직원(`직원` 탭, 이름으로 찾음)에게만 보이고 저장은 `직원` 탭 파트명을 바꿈.
  - 조직도·합계 표에서 **직원 파트가 엑셀 구역보다 먼저**: 전방파트 → 전기·방재, 기건파트 → 기계·건축. 소장·관리파트·공사장 안전관리 줄은 그대로. 구역 순서는 엑셀 순서.
- **직원 삭제 (결정 306)**: 이름 메뉴 맨 아래 빨간 [직원 삭제] → 되묻기 창(「○○ 직원을 삭제할까요?」 · 되돌릴 수 없음) → [삭제].
  - 그 달부터 근무표 줄 지움 표시 · `직원` 사용 중지 + PIN 지움 · 그 직원 기기 로그인 표 모두 지움. 서명·점검 기록은 남김. 자기 자신은 못 지움.
  - 같은 이름이 다음에 올리는 엑셀에 있으면 출근현황에는 다시 보임(로그인은 안 됨).

**7. DB 탭 (WS 시트)**
| 탭 | 열 |
|---|---|
| `근무표` | 월(YYYY-MM) · 순서 · 구역 · 직책 · 이름(공석이면 빈칸) · 일별(그 달 칸 글자 목록, `["휴","",…]`) · 올린사람 · 올린시각 · 삭제여부 |
| `근무변경` | 날짜 · 이름 · 원래값 · 바꾼값 · 바꾼사람 · 바꾼시각 · 삭제여부 (덧붙이기만. 같은 날·같은 사람은 마지막 줄이 이김, 바꾼값 `(되돌림)` = 엑셀 값으로) |
| `기본휴일` | 이름 · 요일(예: `일,월`) · 바꾼사람 · 바꾼시각 |
- 세 탭은 배포 뒤 처음 열 때 저절로 생김 (「① 초기 설정」 안 눌러도 됨). 시트 값은 모두 글자 (결정 54). 종류 코드는 새로 만들지 않음 (한 달 한 묶음이라 ID가 필요 없음).
